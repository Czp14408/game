# 标准世界固定奖励与携带账本 v0.1

> 历史固定测试输入，仅用于复核旧结果，不作为当前规则或数值依据。当前设计见核心规则、世界与内容设计及第一阶段设计方案。

日期：2026-10-13。状态：供给与容量推演候选，尚未确认经济数值；已逐步校验容量与同品质合成。不证明战斗胜率、奖励代表性或最终平衡。

依据：[标准世界分布草案](标准世界分布草案-v0.1.md)、[世界风格测试技能库](../../design/世界与内容设计.md)、[核心规则](../../design/游戏核心规则定稿.md)。使用同一世界、同一组固定合法抽取结果比较三条路线；未访问对象不重抽，不为每条路线分别生成理想奖励。

## 1. 输入与假设

- 三条路线各从独立试炼的相同初始状态开始：武者、初始血族、基础生命100、青铜长刀占战斗栏2格、空背包、起始货币30，点数另按任务记账。
- 战斗栏10格、背包10点。长刀、护身佩、毒针器、回春装置各占2；短刃占1；每件材料、恢复品、支线包裹占1。技能、血液记录与必要主线线索不占背包。
- 初始状态借用已有测试输入，不宣称新经济已认可起始30；本轮不填任何售价、购买价、战斗货币或任务收益数值。
- 假定路线挑战均获胜、采血成功、不在途中主动销毁物品。敌人生命、角色生命损耗与战败尚未模拟；不能用本账本证明深路线实际可生存。
- 集市的固定验证库存恰好有一件青铜回春装置。正常与深入路线选择购买，价格记P，必须在该交易时点付得起；库存只是验证输入，不作为随机保底。
- 未计其他刷新、付费治疗或恢复品自用。若战斗验证需要这些消费，应补回本账本，不把缺失费用误作零成本。

## 3. 主线优先路线

顺序：01→02→03→04→05→06。6个不同节点，消耗5探索时间。

1. 03取得矿片入包，完成主线调查；没有恢复品，不取得传授技能。
2. 04胜利后将青铜护身佩放入战斗栏，记录人类血液。
3. 06胜利后学习青铜越战越勇，开启Boss宝箱。
4. 白银长刀替换青铜长刀，白银护身佩替换青铜护身佩；两件旧装备收入背包，不销毁。
5. 青铜短刃放入战斗栏，恢复药丸收入背包。

最终战斗栏：白银长刀2＋白银护身佩2＋青铜短刃1＝5格。

最终背包：青铜长刀2＋青铜护身佩2＋矿片1＋恢复药丸1＝6点。背包峰值6，没有途中出售。

技能1项：青铜越战越勇。血液1种，初始血族中毒施加量加成为+1；尚未持有中毒物品，不虚构当下中毒收益。

## 4. 正常探索路线

顺序沿分布草案，先完成两条支线及猎场，再返回集市交付与交易，之后推进主线。10个不同节点，消耗9探索时间。

1. 07取得兽皮；11取得包裹与旧铜器；12取得恢复药丸；08战胜后取得兽骨并记录野兽血液。此时背包5点。
2. 返回02交付包裹，出售兽皮、旧铜器、兽骨，共3件材料；保留恢复药丸。交易后背包1点。
3. 购买青铜回春装置，直接放入战斗栏，占2格。能否付款由后续价格与此时收入确认，不假定自动赊账。
4. 03取得矿片，将恢复药丸提交传授事件，学习青铜回春护体；药丸被消耗，不重复计算出售或自用。
5. 04取得并装备青铜护身佩，记录人类血液；06学习越战越勇，Boss宝箱按主线路线处理。

最终战斗栏：白银长刀2＋白银护身佩2＋青铜短刃1＋青铜回春装置2＝7格。

最终背包同主线优先，共6点；背包峰值6。技能2项：青铜回春护体、青铜越战越勇。血液2种，中毒施加量加成+2，仍未取得中毒物品。

青铜回春装置的正常战斗治疗可触发回春护体；血族吸血不能触发。技能来源不是恢复品载体，而是提交代价后NPC传授。

## 5. 深入兽穴路线

顺序沿分布草案，猎场后进入09与10，再返回集市交付交易，之后完成主线。12个不同节点，消耗11探索时间。

1. 与正常路线相同地收集前三处小容器、包裹与猎场材料，记录野兽血液；09再取得药材，背包6点。
2. 10胜利后将青铜毒针器放入战斗栏，记录异化生物血液。宝箱白银毒针器替换青铜毒针器，旧毒针器收入背包，背包8点。
3. 宝箱青铜短刃直接放入战斗栏，腺体收入背包。此时战斗栏5格，背包9点，接近上限但没有丢弃。
4. 返回02交付包裹，出售兽皮、旧铜器、兽骨、药材、腺体共5件材料；保留青铜毒针器和恢复药丸。此时背包3点。
5. 购买青铜回春装置入战斗栏；03取得矿片、交恢复药丸并学习回春护体；04装备护身佩并记录人类血液。
6. 06学习越战越勇，白银长刀、白银护身佩替换旧装备；Boss宝箱第二件青铜短刃与原短刃进行下述合成，最后药丸收入背包。

短刃合成操作：先将战斗栏青铜短刃卸入背包（背包由7到8点），再领取Boss宝箱青铜短刃入包，自动两件合成白银短刃，最终仍占1点，背包仍8点；随后将白银短刃装备回战斗栏，背包降至7。领取最后药丸后背包8点。不是战斗栏自动合成，也不新增手动合成入口。

最终战斗栏：白银长刀2＋白银护身佩2＋白银短刃1＋白银毒针器2＋青铜回春装置2＝9格。

最终背包：青铜长刀2＋青铜护身佩2＋青铜毒针器2＋矿片1＋恢复药丸1＝8点。背包峰值9。

技能2项，血液3种。初始血族给白银毒针器的中毒施加量加成+3；若回归后进阶成功，按已采用系数重算为+6。进阶是否买得起尚未确定，不能提前把+6用于世界战斗。

- 回春装置的购买发生在主线奖励到账前，必须检查购买时点的余额，而非只检查期末余额。
- 点数独立计算：主线路线为主线点数U，另外两路线为U＋两支线点数V_A＋V_B；普通刷怪不追加点数。
- 回归后背包矿片与旧装备是否出售另做消费决策，不能同时算作保留物资和现金。卖旧装备可能改变后续重复合成与换装机会。

## 8. 当前能得出的结论与不能得出的结论

- 已逐步核验三条路线战斗栏与背包不超过10，以及深路线两件青铜短刃通过入包合成白银，不需要新增规则。
- 深路线确实获得更多装备、采集成长和一条中毒联动，但这是本次合法抽取结果，不证明随机总体总能成型。
- 所有收益均可取得，背包9点的紧张被免费重访集市与材料出售缓解；本样本没有发生强制丢弃，不据此宣称容量已形成有意义舍弃。
- 这不是要求立即取消免费重访。后续需用装备偏大、恢复消耗较多、出售地点较远等合法样本检查压力，而非为制造舍弃临时添加收费。
- 血族收集在未持有中毒物品时是未来构筑价值，不把+1/+2直接换算成当前战力。
- 尚未证明回春购买可负担、深入路线存活、主神兑换合理、阶段Boss难度或真实时长；这些需要本账本之后的价格、战斗与行为验证。
