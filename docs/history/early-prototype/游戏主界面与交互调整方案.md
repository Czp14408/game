# 游戏主界面与交互调整方案

> 使用边界（2026-10-15）：本文是旧自由移动原型的界面需求。全屏角色移动、右上小地图与附近设施交互不再作为新版卡牌探索的布局要求；战斗、卡面和物品面板中不冲突的组件约定可以复用。新版公共规则见[核心规则](../../design/游戏核心规则定稿.md)，当前接入范围见[新版节点记录](../../validation/新版节点首批接入-2026-10-14.md)。

2026-10-07｜讨论定稿部分 v1.0｜用户确认的界面调整需求。

> 实现状态更新（2026-10-08）：v0.4–v0.8 的部分交互已在 R0.8 接入，详见 [R0.8 系统组件接入](../../validation/R0.8_系统组件接入.md)。商店拖拽购买与出售落区、商店和底部背包并开、购买前合成预览等仍未完成；本文描述的是需求，不以本页推断全部已实现。

## 1. 主界面

正常状态显示全屏世界内容：地形、角色、NPC、资源、守卫、传送点。主神空间在概念上也作为一个世界，使用可移动、可交互场景承载商店、治疗与阶段挑战等设施。

试炼世界和主神空间右上角均放小型地图，显示当前场景地形、角色位置和附近交互点。完整世界节点关系不放在常驻小地图中。点击小地图打开独立信息页，同时提供 M 切换快捷键。

世界节点地图、任务、情报、目标说明集中在独立信息页。生命、金币、全局生命与十格战斗物品栏移入 Tab 单独唤出的状态栏，不常驻。全局生命即试炼层面的失败次数概念，不新增独立血量或失败额度。

## 2. 商店、背包与整理

- 商店在屏幕上方横向展开，可以单独唤出；先靠近商人或对应设施交互，离开交互范围后关闭。
- 背包在屏幕下方贴底，状态栏在背包上方；商店与背包允许同时操作，整理沿用横向布局。
- 上下区域共用低饱和浅蓝半透明未来系统组件。此前左右半屏排布改为上下排布，源素材需重新适配。
- Tab 打开状态栏时同时显示背包，再次按下关闭状态栏，恢复此前背包的开关状态；这组唤出不停止角色移动。
- B 独立打开背包／整理与商店仍沿用停止移动规则；信息页暂停场景。Tab 联动显示背包不能意外触发暂停；原有其他移动限制仍保留。
- 不通过模式切换远程访问商店。当前商店货位、背包容量、物品占格与不堆叠规则保持。

## 3. 同一战斗界面的状态

### 准备

场景中交互遭遇后直接进入战斗界面，不再单独打开普通战前查看或阶段对手预览页。上方显示敌方物品技能，下方显示己方构筑；通过卡牌悬停说明查看效果、品质、冷却和触发信息。

右侧操作栏承载开始战斗、调整构筑、返回场景。准备阶段不推进冷却、状态或战斗计时。调整后返回同一准备界面，对手配置不变。普通遭遇和阶段挑战共用此流程。

### 战斗

开始后进入自动战斗状态，右侧切换为战斗中的适用操作与日志。返回场景只在准备状态可用，战斗中遵守既定规则。

### 胜利与掉落

不单独进入战后反馈页。胜利后清空敌方物品栏，将唯一掉落展示在敌方栏正中央。物品保持实际占格大小，技能使用独立卡牌样式，同样居中；悬停查看说明并提示“点击领取”。

- 点击掉落物直接拾取到背包，不增加“拾取”按钮。
- 背包空间不足则获取失败，提示“背包空间不足”，掉落保留。
- 技能掉落点击后直接学习；学习失败时按服务结果反馈，不误标为已领取。
- 成功领取后移除掉落展示并短暂提示，防止重复领取。
- 右侧“退出战斗”返回场景，未领取掉落默认放弃，不增加放弃按钮或二次确认。
- 不增加战后整理按钮。
- 阶段首领无掉落，不制造奖励占位；阶段完成后的流转仍按既定阶段规则，不开放返回已封闭世界的入口。

### 失败

失败结果留在战斗界面，显示适用的退出或后续流转操作，不单独进入战后反馈页。没有掉落可拾取。累计三次失败的试炼结束规则保持。

胜负结果以中央简洁提示展示；战斗统计与日志通过右侧区域展开查看，不强制打开独立反馈页面。

## 4. 与既有文档的关系

本方案覆盖旧技术方案中的独立战前预览、独立战后反馈及左右半屏面板安排。最新布局为商店上方、背包贴底、状态栏在背包上方；不改变战斗结算、掉落概率、购买价格、失败次数、背包容量和世界进度规则。工程已有的右侧面板接入记录属于历史基线，不代表新布局已完成。

按钮映射详见《主神空间按钮组件说明》，其中已补充统一战斗准备状态、掉落点击领取及退出规则；后续接入保留原服务层规则。

## 5. 信息页与面板切换（已确认）

- 信息页保留当前世界名称、左侧世界节点地图与右侧任务、目标、情报；生命、金币、全局生命移入状态栏。已确认样稿的主体比例保留，顶部状态内容相应迁移。
- 主线目标优先，支线任务其次，已获得情报支持展开。不增加已探索节点机会汇总。
- 点击小地图或使用快捷键打开信息页。信息页暂停场景，并暂时隐藏商店、背包及状态栏；关闭后恢复打开前的有效面板及移动规则。
- 信息页的打开与恢复不能重生成商店、重置选中项或丢失世界进度；商店上下文如已失效，不恢复无效商店。
- Esc 先关闭最上层提示或页面；商店与背包并开时，优先关闭最后操作的面板。打开信息页时 Esc 先关闭信息页，再恢复原面板。
- 所有阻止移动的面板关闭后恢复控制，角色保持原位，不自动继续此前的移动。
- 靠近可交互对象时显示简短名称和交互键，交互后显示详细操作。Tab 状态栏与其联动背包不停止移动，其余面板按各自规则处理。
- 上述通用 Esc 关闭规则适用于场景页面与面板，不使进行中的战斗能够返回场景；战斗阶段的关闭与退出限制仍按第3节执行。

## 6. 快捷键与场景交互（已确认）

| 输入 | 行为 |
| --- | --- |
| E | 与当前提示的可交互对象交互 |
| Q | 循环切换交互范围内的可交互对象 |
| B | 独立切换下方背包／整理；与商店并开时不关闭商店 |
| Tab | 切换状态栏；打开时显示底部背包，关闭时恢复原背包开关状态，不停止移动 |
| M | 切换信息页；再次按下关闭，恢复打开前仍有效的面板状态 |
| Esc | 按第5节关闭最上层提示、页面或最后操作的面板 |

快捷键切换不绕过战斗中禁止整理与返回场景的限制。信息页处于前台时不让 B 或 Tab 操作隐藏面板。一次按键只产生一次切换，避免按住键重复开关。Tab 开关仅改变显示状态，不复制物品或重新生成背包。

靠近可交互对象后提示简短名称与 E。多个对象相邻时默认选择最近的可交互对象；对象重叠时允许切换目标。资源领取后变为已消耗外观，不再显示领取提示。已完成 NPC 保留人物和必要对话，仅移除已完成的一次性操作。

## 7. 状态栏补充与物品拖拽（已确认）

全局生命显示“剩余机会 3/3”，失败一次减少一次，悬停解释累计三次失败结束。数值由失败次数推导，不增加第二套计数。联合显示时，Esc 在无更上层页面时先关闭状态栏并恢复此前背包状态；B 只切换背包，状态栏保持显示。

物品移动与相对位置调整改用拖拽，不再依赖装备、卸下按钮。其他物品根据落点自动让位重排；容量不足则不能放入，整次操作回退。

| 来源 | 目标 | 行为 |
| --- | --- | --- |
| 背包或战斗栏 | 同一栏的新位置 | 调整相对顺序，其他物品自动让位 |
| 背包 | 战斗栏 | 可装备物品放入落点 |
| 战斗栏 | 背包 | 卸下并放入落点 |
| 商店商品 | 背包 | 购买后直接放入目标位置 |
| 商店商品 | 战斗栏 | 可装备商品购买后直接进入目标位置 |
| 持有物品 | 当前商店售卖区 | 按既定回收价出售 |

拖拽按物品实际占格校验最终容量。同栏重排不得重复计算自身。失败恢复原位置和其他物品顺序；购买失败不扣币、不消耗货位，不强制先占背包再移入战斗栏。无效落区或取消拖动不改变状态。

售卖区需明确区别于商品展示区，仅在有效商店上下文启用。战斗中不能整理或交易。自动让位不丢弃或出售其他物品；进入背包时自动合成按第8节处理。

移动、装备、卸下、购买、出售由拖拽承载；恢复品使用和丢弃改为右键物品菜单，不在背包旁设置独立操作按钮。关闭背包通过快捷键；商店刷新、锁定保留独立入口。手动合成按钮由第8节入包自动合成规则替代。

## 8. 技能栏与自动合成（已确认）

技能使用独立技能栏管理，在状态界面和战斗界面均展示，不占物品栏容量。此处尚未定义技能装备上限、主动释放、出售或取消生效，沿用既定已学技能全部生效与无数量上限规则；内容过多时须可访问全部技能。

物品自动合成时机统一为进入背包：购买拖入背包、战后点击拾取、从战斗栏卸下等入包操作均参与。只检索背包内同名同品质的合法候选，多个候选按显示位置从左到右、从上到下选择。进入战斗栏、商店商品直接购买到战斗栏、同栏调整顺序均不触发合成；不跨栏消耗已装备物品，不再提供手动合成按钮。

产物替换优先命中的候选位置，其余物品紧凑排列。允许连续升级：若新品质仍有同名同品质背包候选则继续合成，直到没有候选或达到钻石。钻石重复件作为独立物品接收，仍需容量，不叠加为一件。

容量按连续合成后的最终占用校验，满背包也可接收最终能容纳的可合成物品。购买、入包、全部合成、来源移除与扣币作为整次提交；失败完整回退，不扣币、不消耗商品或原实例。预览不改变真实状态。

同栏拖动采用插入后紧凑排列，其他物品依次让位，预览放置结果；不自动将其他物品交换到另一栏。商店操作区提供明确“拖到此处出售”的落区，拖入预览回收价，松手出售。

自动合成继续沿用同名同品质两件合为高一品质、钻石不再升级、永久成长相加、战斗临时成长不继承等既定规则。商店技能拖入独立技能栏购买并学习，战后技能掉落仍点击学习；技能不进入背包，不参与物品入包合成，同名技能按原学习规则处理。

物品边框采用方形／方正矩形，随占格大小横向扩展；技能边框采用圆形。此区分用于商店、背包、状态栏、战斗栏、掉落与悬停信息中的物品或技能展示；不要求把多格物品压成正方形。品质颜色作为第二层识别，不替代形状。面板与功能按钮继续沿用自身系统样式。

本次规则覆盖旧版手动合成入口；工程服务与相应验证需按入包自动合成修订，不能沿用旧路线的交互步骤宣称新规则已验证。

## 9. 整备样稿与背包菜单（已确认）

已认可 `ui/concepts/preparation_layout_v1/preparation_layout.png` 的上下布局，包括状态栏右侧独立技能区及整体区域比例。图中格位编号和物品大小仍为示意，工程按真实十格计算。

背包不再显示样稿中的“使用／丢弃／返回”按钮，移除独立操作条或将其空间归还物品区域。右键具体物品打开上下文菜单，只显示该物品适用的操作：恢复品可使用，持有物品可丢弃。满血恢复品使用不可用；丢弃继续采用已确认的危险操作确认规则。

右键菜单不另提供手动合成、装备／卸下、购买／出售，避免与入包自动合成及拖拽规则重复。材料不出现使用或装备选项。菜单打开期间仍以当前物品实例为目标，执行时再次验证持有关系。

背包通过 B 开关；Tab 联动与 Esc 关闭顺序保持既定规则。右键菜单属于最上层提示，Esc 优先关闭菜单，不同时关闭背包或状态栏；拖动、物品消失或所属面板关闭时清除失效菜单。菜单应限制在屏幕范围内。

## 10. 共用悬浮信息（已确认）

已认可 `ui/concepts/tooltip_layout_v1/tooltips.png` 的信息层级与视觉风格。物品说明显示名称、品质、占格、冷却、效果和被动；技能说明显示名称、品质、触发条件和效果，并明确自动生效、不占物品格；剩余机会说明累计三次失败结束试炼，治疗不恢复机会。

操作提示随当前页面和阶段变化，商店显示价格与购买目标，掉落显示点击领取或学习，背包显示适用的拖动与右键操作；战斗进行中不展示整理或交易提示。三类说明按悬停目标分别出现，不同时作为独立页面弹出。样稿尚未接入工程。

## 11. 拖拽、合成与技能溢出反馈（已确认）

- 拖动时原位置保留淡影，目标栏预览落点及其他物品让位后的最终排列。合法目标采用浅蓝提示，非法目标采用红色并显示原因；失败恢复完整原状。
- 购买预览价格与预计剩余金币；售卖区预览回收价。松手提交，失败保持商品、金币、物品及原位置。
- 入包合成预览最终品质与占格，成功后在合成位置短暂闪光并显示品质变化。连续升级合并为一次反馈，不弹确认窗口。
- 技能栏保持单行圆形图标；内容溢出时，鼠标悬停技能区使用滚轮横向浏览，仅溢出时显示两侧箭头，不影响物品栏。
- 容量不足、金币不足、无法装备等操作失败在目标附近短暂提示，约两秒消失，不阻挡后续操作。

主神空间反馈沿用浅蓝半透明系统风格；战斗界面保留自身背景与边框风格，统一反馈含义。预览不修改真实数据，提交时重新校验。

## 12. 交互边界与信息查看（已确认）

- 相邻交互对象默认选最近目标，Q 循环切换交互范围内的对象；当前目标显示轮廓与名称。目标离开范围或失效后重新选择有效目标。
- 拖动过程中 Esc 优先取消拖动，不同时关闭面板。关闭来源面板、进入战斗或商店上下文失效时取消拖动，恢复原位置，不提交交易或合成。
- 悬浮说明靠近目标显示，并限制在屏幕内；开始拖动时隐藏详细说明，仅保留落点、容量及交易反馈。
- 战斗进行中允许悬停查看物品、技能与展开统计，战斗继续运行；禁止整理、使用背包恢复品和交易。
- 小地图显示当前位置及已发现的交互点，不提前暴露未发现内容。完整世界节点关系仍由信息页承载。

上述拖动取消规则优先于通用 Esc 面板关闭规则；预览期间没有真实数据变化，取消不会产生购买、出售或合成。

## 13. 接入时调整的表现细节

以下可在布局样稿与工程接入时细化：

- 小地图、信息页与交互提示的实际尺寸、字号与边距。
- 统计展开区域的实际大小。
