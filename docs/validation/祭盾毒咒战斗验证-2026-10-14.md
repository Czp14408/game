# 祭盾毒咒战斗验证

采用用户选择的持续支付模式B。证据：[脚本](../../_验证/ritual-combat.mjs)、[结果](../../_验证/ritual-combat-results.json)。原39项战斗检查及新支付边界断言通过。

## 范围

三种固定10格构筑，对三种固定敌人，各比较无技能/黄金技能/钻石技能，50个种子，共1350场。双方生命1300，物品青铜，效果倍率5、沙尘暴倍率4；玩家额外有15%吸血及物品中毒加成4，敌人没有血统或技能。这是偏玩家的机制对照，不是平衡验收、获取证明或整体通关率。

## 观察

- 所有组均为50/50胜出，胜出次数饱和，不能据此宣布技能平衡。
- 多盾构筑对攻击模板：无技能28秒，黄金18秒，钻石15秒；两个品质均支付6次、消耗240盾，额外中毒90/150。
- 多盾构筑对诡异模板：无技能29秒，黄金17秒，钻石14秒；支付8次、消耗320盾，额外中毒120/200。
- 钻石可能因更早结束战斗而支付更少，支付次数不是收益强度或资源效率的独立指标。
- 当前原始换算为黄金8盾换3毒、钻石8盾换5毒；倍率同时扩大成本与收益，没有让低代价复制高生命收益。

## 边界

已验证同一步攻击消耗盾后再支付、资源不足没有欠账、两件同刻施毒不吞独立事件、每步至多一次且自触发下一步、战斗死亡不再扣盾、施毒当步不跳伤、技能毒不复制血族加成、支付不产生护盾使用收益。尚未覆盖完整探索、冻结施毒源专项、敌人持有此技能及多种付费技能竞争。未修改游戏工程或Excel。
