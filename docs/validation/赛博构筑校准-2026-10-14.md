# 赛博构筑校准

证据：[脚本](../../_验证/cyber-calibration.mjs)、[结果](../../_验证/cyber-calibration-results.json)。1800场固定对照，四种10格赛博组合、三种技能设置、三种敌人，每格50个种子。双方生命1300，物品白银，效果倍率5、沙尘暴倍率4；玩家有15%吸血，敌人使用既有模板技能但无血统。不是获取过程或总体通关率。

技能设置：原生稳压回路0.3秒；强化回路0.8秒（钻石值，属于越档敏感性检查）；共享成长为原生回路加越战越勇2。没有把越档值当作白银正式参数。

| 构筑 | 防御敌人：原生/强化回路/共享成长胜出次数 |
| --- | --- |
| 原始混合设备 | 3 / 5 / 50 |
| 单无人机组合 | 17 / 24 / 50 |
| 双无人机双电池 | 50 / 50 / 50 |
| 双医疗组合 | 6 / 9 / 33 |

每格分母50。所有组合/设置对攻击与异常模板均为0/50，不能通过防御模板的提升宣称赛博已经达标。双无人机可突破慢速防御，但仍欠缺在压力下的持续输出。单纯把回路提高到钻石值改善有限。

## 后续设计选择

现有随机充能及医疗供能机制仍保留。用户明确测试版偏弱不阻塞，正式迭代再增强。本轮不新增充能驱动成长机制，也不继续为数值平衡延误内容闭环；以上保留为后续调参证据，不再列为待用户决策。
