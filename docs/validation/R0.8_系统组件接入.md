# R0.8 系统组件接入（system_components_v1）

## 接入范围总览
- 新素材 `assets/ui/system_components_v1/`（7 张面板）经 **SystemSkin**（`scripts/ui/system_skin.gd`）接入 3 个页面。
- 生成器 `tools/build_system_components_ui.py` 在 manifest.json 之外新增输出 **layout.json**（1280×690 设计画布上的页面坐标与命名子区），页面坐标不再写死在 GDScript。
- 第二批（v0.4–v0.8 交互方案，依据《游戏主界面与交互调整方案.md》）：拖拽、入包自动合成、Tab/B/Esc 状态链、技能栏溢出滚动、统一战斗界面（结果与掉落留战斗页）、信息页重排、商店落位屏幕上方、入包合成闪光。

## 服务层与控制器（第二批）
- `inventory_service.move_item`：拖拽移动/重排。占格按绝对格位插入（`_insert_at`），其余物品自动让位；先副本校验后 `_commit`，任何失败整次回退。
- `inventory_service.auto_synthesize_into`：入包自动合成（§8）。只合成**可装备物品**（材料/恢复品 `equippable=false` 不参与）；候选按背包显示顺序取第一个；连续升级到无候选或钻石；按最终占用校验容量；来源移除/合成/入包整次提交。`pickup` 即此入口（购买入包、搜刮、掉落领取共用）。
- `economy_service.buy_into`：商品购买到指定栏位（战斗栏不合成、入背包走自动合成）；`buy` 物品分支改走同一合成入口。返回的 `instance_id` 恒为**最终产物**（合并发生时购入件已被消耗），附 `merged`/`produced_quality` 供界面反馈。
- `run_controller`：`move_item`/`buy_into`/`preview_auto_synth` 转发；`toggle_status_bar`（Tab 联动）/`toggle_bag`/`status_bar_open`/`bag_open` HUD 状态；`settle_battle_inplace`；`open_container_here` 回传 `landed_ids`/`merges` 供闪光。
- 输入映射重做：`open_world_map`=M（原 Tab 大地图语义移交）、新增 `toggle_status`=Tab；`ui_smoke_test._test_input_map` 同步。

## 过程中修掉的坑（新增两条见「真渲染才暴露」）
1. **NinePatchRect 没有 `expand_mode`/`stretch_mode`**（那是 TextureRect 的属性）——赋值报错使函数中止，整块面板消失。
2. **`Dictionary.get(key, default)` 对「键存在但值为 null」返回 null**：manifest 里 JSON null 给 typed Array 赋值报错，SystemSkin 取值全部显式 `is Array` 判空。
3. `_gold_label` 重复 `add_child`、`abs_sys_label` 参数顺序等小错。
4. **入包自动合成最初把材料也当素材吞掉**（18 项回归失败）：修复为 `equippable=false` 不参与；同时把测试夹具 `_hold` 改为**直塞背包不经 pickup**（自动合成在夹具阶段就会合并同名件，破坏受控前置状态）。
5. **信息页任务列表真渲染整块空白**：ScrollContainer + 自动换行 Label（clip_text）最小高度塌陷，战斗日志踩过的同一坑——改用 RichTextLabel（`abs_log`）自管换行滚动，行内配色走 bbcode。
6. **自动演示断言未跟上统一战斗界面**：战后不再进 PagePostBattle，`ui_autoplay` 改为断言「战斗结束留在战斗页」。

## 验证结果（最终）
- 无画面回归：**890 通过 / 0 失败**（含新增拖拽/自动合成、闪光帧推进、商店落位断言）。
- 真实帧自动演示：**21 项 0 失败**（`--auto-demo 20261007`）。
- 真渲染截图：**128 通过 / 0 失败**（1280×720 与 1920×1080），输出 `_验证/截图_r0.8_v4/`；商店面板已在屏幕上方，信息页任务/情报可见，战斗页掉落/统计抽屉正常。
- 闪光机制按「帧推进 + 真实时间」双守：叠加层建立即存在、0.7 秒真实时间后自毁（tween 是真实时间驱动，无画面模式帧率不封顶，按帧数等不到）。
