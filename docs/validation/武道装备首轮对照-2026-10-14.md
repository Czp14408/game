# 武道装备首轮对照

日期：2026-10-14。状态：独立设计模型已完成基础行为检查与固定构筑对照，未接入Godot，不证明正式战斗、随机供给或完整试炼平衡。

依据：当时武道装备行为与参数已汇入[世界与内容设计](../design/世界与内容设计.md)武道装备部分。可复算资料：[设计验证模型](../../_验证/wudao-balance.mjs)、[固定输入与结果](../../_验证/wudao-balance-results.json)。执行方式：`node _验证/wudao-balance.mjs --write`。此次没有修改旧验证模型、Excel或生成资源。

## 1. 输入与范围

- 0.1秒结算步长，双方基础生命100、满血开场；自然冷却从完整CD开始。所有装备每周期使用一次，无职业、血统或额外强化。
- 双方先锁定效果，再加盾与治疗、攻击及既有中毒跳伤、沙尘暴、死亡检查，存活时执行加速、成长和使用事件连锁。新中毒不在施加当步跳伤，充能就绪最早下一步释放。
- 同帧全体攻击快照先锁定，因此护盾使用成长不回写本步攻击，其他武器同帧使用不增强已锁定的重击。
- 第30秒起沙尘暴每秒伤害5、10、15……，双方同时受伤。双方同死按玩家失败记录，结果另记同死次数，不能把镜像构筑同死解读成玩家构筑更弱。
- 固定对手为攻击、防御与中毒三类同品质9格构筑，不是地图敌人或阶段对手定稿。青铜与白银分别对同档对手；没有用全部黄金装备打青铜敌人制造成长优势。
- 基线36个组合各运行种子1—100，共3600次；追加3个青铜技能样本各100次，总计3900次。没有随机目标或暴击时，重复100次仍是同一确定性战斗，不是100份独立证据，更不是总体通关率。
- 另有30秒无敌靶输出探针，固定种子1且不因死亡停止，用于记录释放量，不计算胜率、吸血或实战存活。它仅在指定时段检查数值，不当作战斗合法结局。
- 27条断言通过，覆盖品质缺档、容量、充能次步释放、首击蓄势、同帧蓄势、双锤互相积蓄、新中毒跳伤、满血与低血治疗、加速重复延时、神风剑CD下限、同帧成长快照、死亡停止连锁及可复现随机输入。

本模型不实现血族吸血与血液加成、职业、减速、冰冻、多重使用、技能充能环或探索资源。上述内容不能从这份结果宣称已验证。特别是攻击实际生命伤害归属尚未定稿，不在这里偷偷指定吸血分配方式。

| 名称 | 装备 | 占格 |
| --- | --- | --- |
| 基础攻击 | 长刀、重锤、短刃、轻盾、药葫芦 | 9 |
| 快攻成长 | 短刃、长刀、剑穗、磨刀石、两件轻盾、药葫芦 | 9 |
| 蓄势混合 | 短刃、长刀、破岳锤、轻盾、药葫芦 | 9 |
| 蓄势快兵 | 三件短刃、破岳锤、轻盾、药葫芦 | 9 |
| 攻防基础 | 短刃、长刀、护心镜、两件轻盾、药葫芦 | 9 |
| 短刃压力 | 四件短刃、护心镜、药葫芦 | 8 |
| 毒术旁路 | 两件淬毒针、长刀、护心镜、轻盾、药葫芦 | 9 |

破岳锤两组只运行白银。短刃压力刻意少一格，不伪装成严格同格对照；用于检查多武器使用的输出与充能双重收益。各装备只在战斗栏持有，不经过背包，因此允许同名同品质同时参战，不与入包自动合成规则冲突；其实际获取难度未测试。

攻击对手使用“基础攻击”；防御对手为长刀、护心镜、两件轻盾、药葫芦、磨刀石；中毒对手使用“毒术旁路”。所有对手使用与玩家相同的模型。

## 3. 固定样本结果

数值为100次中玩家胜出次数；0包含双方同死，详见结果JSON。不能把不同对手的胜数平均成正式胜率。

| 构筑 | 青铜对攻击/防御/中毒 | 白银对攻击/防御/中毒 |
| --- | --- | --- |
| 基础攻击 | 0 / 0 / 0 | 0 / 0 / 0 |
| 快攻成长 | 0 / 100 / 0 | 16 / 100 / 0 |
| 蓄势混合 | 不支持 | 0 / 0 / 0 |
| 蓄势快兵 | 不支持 | 100 / 100 / 100 |
| 攻防基础 | 100 / 0 / 0 | 100 / 0 / 0 |
| 短刃压力 | 100 / 0 / 0 | 100 / 0 / 0 |
| 毒术旁路 | 100 / 100 / 0 | 100 / 100 / 0 |

关键过程：

- 白银蓄势快兵对攻击组10秒获胜、剩24生命；对防御组21秒获胜、剩68；对中毒组14秒获胜、剩15。蓄势混合不能因此被直接判为破岳锤数值不足，辅助出招效率是决定性差异。
- 青铜短刃压力8格对攻击组20秒胜、剩68；青铜攻防基础9格拖到33秒才胜、剩8。多短刃确实同时提供输出和护心镜充能，风险未被消除；但它在本组防御与中毒对手前失败，不是所有对手都通吃。
- 青铜毒术对防御组25秒胜、剩100；白银19秒胜、剩100。此处还没有血族加成，毒术已有较强绕盾优势，应优先扩展低生命、爆发与真实供给样本，不再给中毒旁路免费叠加奖励。
- 无技能攻防主要获得防护，不自动取得反向攻击成长。加入青铜越战越勇后，对青铜攻击组由33秒/剩8改善为18秒/剩84；短刃压力加入同技能为12秒/剩82。技能是重要启动组件，不可视为白送的背景属性。
- 快攻成长加入青铜磨锋入微，对青铜攻击组由0/100变为30/100，平均结束21.21秒、平均玩家剩余生命9.84（含失败的0）。这不证明快攻路线普遍过弱，需要分别对照剑穗与磨刀石的投入，而非只测试同时占两个支持格。

## 4. 神风剑与释放量

- 黄金神风剑加剑穗共3格，在30秒固定靶探针中释放12次、总攻击296，战后记录攻击成长10、有效自然CD3秒。
- 黄金长刀加短刃同为3格，总攻击331；单件黄金长刀2格为196。前者才是同格对照，不能只用神风剑组合对单长刀的增量宣称优势。
- 单剑穗在第30秒的第五次加速才提供最后一次成长，这次成长不回写已锁定攻击。黄金神风剑此时仍未达到2秒下限。
- 白银蓄势混合30秒总攻击388，蓄势快兵522；这两组均9格、同品质。固定靶攻击量不考虑攻击被护盾吸收、过量攻击或先死亡造成的损失，只能解释输出机制。

## 5. 本轮直接采用的推进决定

用户已授权常规测试决策直接推进。第8节参数由“等待逐件确认”转为“当前采用的可调整测试输入”，不等于正式平衡定稿。

1. 暂保留现有参数，不因单组失败直接加强破岳锤或神风剑；先排除组件配置不合适与比较占格不一致。
2. 新增三短刃驱动破岳锤作为压力输入，不以其全胜作为标准世界必得构筑，不额外新增物品。
3. 第一阶段供给不保证多短刃与越战越勇同时获得，测试应同时包含无技能、低血、少武器和未成型路线。随机供给不专门根据玩家需要匹配。
4. 旧容器数量和地图可以作为结构输入，但旧敌人装备、奖励账本与阶段对手配置暂不直接替换；先重新列出新实际配置，再按同一组掉落推进携带和交易。
5. 血族、控制与治疗环是下一批模型工作；若必须确定尚未定稿的全局伤害归属或多重使用规则，应单独明确，不能用一次模型实现暗中定稿。

下一步优先做第一阶段新敌人配置与固定供给账本，再验证未成型路线，不继续扩装备目录或急着制作美术。
