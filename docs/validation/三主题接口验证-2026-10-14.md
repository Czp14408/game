# 三主题接口验证

日期：2026-10-14。状态：三主题范围及攻击优先抵挡已确认，新增赛博9件、诡异8件测试定义及接口已接入独立模型；900场固定构筑对照已按现规则重跑。未改Godot、Excel或美术。

证据：[接口模型](../../_验证/three-theme-bridges.mjs)、[输入与结果](../../_验证/three-theme-bridges-results.json)。依据：[赛博体系](../design/世界与内容设计.md)、[诡异体系](../design/世界与内容设计.md)。所有新参数只属于设计测试，不代表现有工程已支持。

## 1. 阶段抽取范围

武道/赛博覆盖1—3阶段，诡异覆盖2—3，神厨不进入首批抽取。当前测试候选等权、无放回选两个：第一阶段固定有武道和赛博，后两阶段三个无序主题对的概率各1/3。玩家最终选择不是随机50%，不能把候选权重写成实际世界选择比例。不同阶段允许同主题再次出现，但任务世界必须独立，资源不继承为旧世界重访。

## 2. 新增接口检查

既有39项基础检查继续通过。新增16条检查覆盖：纳米雾罐缺档、灼烧施加当步不跳伤、跳伤后每秒衰减1层、火势护体只由施加触发、治疗至护盾/中毒充能、充能到就绪下一步释放、异构接驳首次启动与无目标机会消耗、冰冻暂停后续行动、血族吸血不发治疗事件、护盾分配对吸血的影响。已锁定行动不被新冻结取消由模型结构遵守，尚未增加专门的同帧临界断言。

稳压回路与瘟血回响按实例每效果每逻辑步最多一次，多治疗事件入队并锁定目标/值，旧队列先于新事件；无合法目标不补发。异构接驳一次技能动作覆盖全部合法异常物品，不把多目标错误拆成每帧只能充能一件。

模型没有物品移除、事件支付、灼烧额外使用、自由表达式或通用导入能力；没有覆盖所有队列异常和控制组合，不能宣称公共技能系统已完整实现。

## 3. 跨世界实际接口

- 赛博医疗包的治疗可触发武道回春护体、赛博稳压回路、诡异瘟血回响；吸血不触发三者。
- 赛博电池可推进武道长刀、护心镜、诡异咒烛或毒液瓶，不要求相同主题标签。
- 赛博加速模块可选合法其他主动设备，区别于剑穗只选武器；可支持护腕与神风剑的既定加速事件。
- 诡异药咒香同时提供正常治疗和灼烧施加，可连接回春护体、火势护体和两条治疗充能技能。
- 防卫无人机一次使用具有武器与护盾效果事件，可以接越战越勇；咒刃攻击可以吸血，中毒不能吸血。

## 4. 固定样本结果

六组玩家、三类对手，每组50个固定随机种子，共900场。双方均1300生命、白银装备、10格，基础效果倍率5、沙尘暴倍率4。玩家统一附15%吸血及中毒加成4，对手无血族；技能也不完全相同，因此不是完全镜像强度测试。所有组合是假定已经拥有，不模拟获取成本，重复种子不是900份独立世界证据。

当前结果已采用攻击优先抵挡；初轮比例分配结果独立保存在[历史模式对照](../../_验证/three-theme-bridges-proportional-results.json)。重跑后下表胜出次数未变，但部分含灼烧与吸血样本的剩余生命发生变化，详见两份结果。各格为50次中胜出数，不能当作总体胜率。

| 玩家 | 攻击对手 | 医疗防护对手 | 异常对手 |
| --- | --- | --- | --- |
| 武道成长 | 50 | 50 | 50 |
| 赛博火力供能 | 0 | 3 | 0 |
| 诡异治疗异常 | 0 | 50 | 50 |
| 武道＋赛博 | 19 | 50 | 50 |
| 赛博＋诡异 | 0 | 50 | 50 |
| 武道＋诡异 | 50 | 50 | 50 |

跨世界接口可以工作，但不能据此证明三主题平衡。纯赛博样本缺少武道成长，随机电池投向分散，当前火力表现偏弱；需继续比较无人机、供能目标、直接武器效率与实际价格，不因输出低就强制附赠越战越勇。诡异样本对医疗防护有效、对攻击脆弱，应保留补防御或控制的取舍，而非让异常所有对手都通吃。

## 5. 已确认：护盾吸收的归属

用户现已确认攻击优先抵挡，剩余护盾抵挡灼烧。此前已定的“抵挡后实际生命损失按伤害占比分摊”仍保留；中毒与沙尘暴不参与护盾吸收层分配。

例如该帧有7护盾、攻击12、灼烧1：若先抵挡攻击，攻击打生命5、灼烧1；若按可抵挡伤害占比吸收，攻击打生命约5.538、灼烧约0.462。总生命伤害同为6，但攻击吸血基数不同。

模型保留两种模式对照：包含前一次攻击的8秒样本，攻击优先恢复1生命，比例分配恢复约1.054。当前只采用前者；多个攻击来源仍按各自贡献分摊同一帧攻击抵挡和实际生命伤害，不通过物品排列产生固定先手。
