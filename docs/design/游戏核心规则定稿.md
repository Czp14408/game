## 0. 术语与作用范围规范

### 四个尺度

| 术语 | 定义 | 边界 |
| --- | --- | --- |
| 试炼 | 从开始一次游玩到通关、失败或认输结算的完整流程 | 包含三个世界阶段，以及主神空间整备、阶段 Boss 挑战 |
| 世界 | 一次可探索的任务世界，拥有自己的主线、节点地图和探索行动时间 | 回归主神空间后不能再进入该世界；整备与阶段 Boss 挑战不属于刚离开的任务世界 |
| 节点 | 世界大地图上的一个地点，以分区卡牌组织探索对象 | 可以包含多个遭遇、容器、事件和战斗；退出节点不等于回归主神空间 |
| 战斗 | 从合法挑战或强制触发开始到分出胜负的一次自动战斗 | 常规节点遭遇与主神空间阶段 Boss 挑战均使用战斗规则 |

- 世界内的尺度关系为：试炼 → 世界 → 节点 → 战斗。主神空间整备和阶段 Boss 战斗也属于试炼，但不强制归入某个任务世界或探索节点。
- “阶段”指一个世界的探索、回归整备与阶段 Boss 挑战组成的流程段，不作为第五种效果持续范围。

### 成长与持续范围

- “本场战斗”：战斗内临时成长与状态，战后清除。未标注更长持续范围的物品数值成长默认属于此类。
- “本节点”：仅在当前节点范围生效。是否进入该节点即生效、离开后如何失效，由具体效果明确；尚未据此增加新的成长机制。
- “本世界”：仅在当前任务世界生效，回归后失效；尚未据此增加新的成长机制。
- “本次试炼”：跨战斗、跨节点、跨世界保留，通关、失败或认输结算时清除。
- 此前讨论的“永久增加”统一解释为“本次试炼内永久增加”，不代表跨试炼保留；正式效果文本优先明确写出“本次试炼”。
- 不再单独使用“局内”“局外”说明持续范围，分别写明“战斗内/战斗外”或“试炼内/试炼外”，避免将战斗与试炼混为一谈。
- 战斗状态与临时数值变化中，只有当前生命跨战斗保留；这不清除物品持有、品质、已学技能或明确标注的本次试炼成长。
- 第一版不做跨试炼物品保留；试炼结束清除本次试炼获得的物品、货币、任务点数、技能和成长，不将其带入下一次试炼。

## 1. 试炼结构与胜负结算

### 已定规则

- 每次开始独立试炼，目标时长约 45 分钟。
- 按三个世界阶段组织，每阶段包含世界探索、主神空间整备和阶段 Boss 挑战，目标约 15 分钟。
- 约45分钟试炼、约15分钟阶段以重复游玩的熟练玩家为节奏目标，不是首次阅读和理解剧情的时间硬上限，也不是现实时间倒计时。
- 阶段流程：进入任务世界 → 完成主线任务 → 选择继续探索或回归 → 主神空间整备 → 挑战阶段 Boss。
- 不同世界对应前期、中期、后期，构筑强度随阶段明显提升。
- 世界按主题系列组织，每个主题明确支持一个、两个或三个阶段；不要求所有主题补齐三阶段内容。各可出现阶段有匹配的强度版本，越后期的怪物、阶段对手与物品供给整体越强；强度可来自数值、频率、成长效率或联动能力，不仅是伤害倍增。
- 首批主题已采用武道、赛博、诡异：武道与赛博覆盖第一至第三阶段，诡异先覆盖第二、第三阶段；神厨仅预留，不进入首批世界抽取。血族对应的世界交易优先纳入诡异，不另开首批独立血族世界。
- 每阶段从支持当前阶段的世界中提供两个候选供玩家选择，抽取不根据玩家构筑专门匹配。阶段覆盖范围与抽取权重分别制定，不因覆盖三阶段而自动获得更高抽取优先级；候选不足时的补足规则待确认。
- 不同主题可在一次试炼中穿插出现。同主题再次出现仍是新的任务世界，任务与局面应有变化，不允许重返已回归的世界搬取物品。
- 阶段 Boss 是其他试炼者，采用“构筑模板 + 随机组件”，与玩家共用战斗规则。第一阶段公共池允许武道、赛博及合法混合构筑；主要随机装备与技能，职业血统按模板固定。核心组合保留，随机后校验容量、品质、目标及联动，不按玩家所选世界定向匹配。
- 对手按阶段强度生成，不依据玩家当前构筑专门生成克制配置；生成后固定，重试保持同一对手与配置。
- 回归后、主神空间整备开始时即可查看阶段对手的生命、物品和被动技能，再决定消费与构筑调整。
- 主线任务与阶段 Boss 挑战分开。每个世界有明确的任务目标，可采用击败任务敌人、取得物品或完成事件等形式；具体任务内容按世界设计。
- 每个主线任务完成后均有任务奖励，完成时自动结算，无需返回委托 NPC 领取；与任务敌人的战斗掉落分开记录。货币直接入账，实物仍遵守拾取与容量规则，技能仍遵守即时学习规则；奖励类型与数量后续制定。阶段 Boss 仍不提供奖励。
- 唯一且必须取得的主线凭证进入任务记录，不占普通背包，不因误丢或容量不足锁死主线；其余可携带奖励继续遵守实物容量规则。
- 支线任务允许同时接取多个，可包括人物挑战、指定敌人击杀、收集交付等形式；货币、装备、技能或情报等奖励视任务而定。材料交付用途暂不制定，不据此要求第一版实现材料交付任务。
- 支线领取方式视任务而定，人物挑战等可现场结算，委托类任务可要求返回对应 NPC 交付；任务应明确领取条件，不默认所有支线完成即自动发奖。
- 主线提供基础任务点数与货币收益，具体任务可另给装备或技能；支线可提供额外点数或特殊兑换资格，数值及具体内容待制定。普通刷怪不默认重复产出任务点数。
- 主线任务未完成时不能正常回归；完成后可直接回归，也可以继续在当前世界探索。
- 主线未完成且无法继续推进时，可在已开放节点继续处理可达目标；资金不足可通过搜刮、战斗或交易筹资，但货币不默认恢复探索行动时间。时间耗尽的任务后果按第2节处理；仍无法完成主线时可以主动结束试炼，按失败结算，不视为正常回归。
- 回归后不能再次返回该世界。
- 主神空间整备提供购买、整理、合成和交易的机会，为搜回的物资提供消费端；整备后挑战阶段 Boss。
- 回归集中展示任务所得、携带物资与可用强化资源，玩家主动选择出售、保留和兑换，不自动卖掉全部战利品。任务收益仍按领取条件结算，不统一延后到回归才到账；任务点数满足条件后记账，主要在主神空间消费。
- 单场战斗生命直接使用角色当前生命，战斗开始不自动恢复满血；生命损耗跨战斗保留。
- 世界内通过消耗品、治疗地点和物品效果恢复生命；主神空间治疗暂不收费，玩家点击即可恢复满血，不在回归瞬间自动恢复。此前主神付费治疗方案由此替代。
- 战败后若本次试炼尚未结束，免费恢复一定比例的最大生命；恢复比例为暂定数值。
- 全局生命采用可承受战败次数，与角色当前生命分别记录；单场战败消耗一次，全局次数耗尽才结束本次试炼。
- 本次试炼内战败次数不恢复，治疗只恢复角色当前生命。
- 世界探索中战败后保留已有装备与背包，返回当前节点入口；失败战斗不产生奖励。
- 已领取资源不刷新，已击败敌人不复活；失败遭遇恢复到战前状态，战斗内临时效果清除。
- 阶段 Boss 战败消耗一次全局战败次数；若次数尚未耗尽，返回整备界面，可调整构筑后重试。
- 阶段 Boss 重试维持同一对手与配置；整备时允许继续购买、付费刷新、治疗和合成，商店不因战败免费重置。
- 必须击败当前阶段 Boss 才能进入下一世界。
- 阶段 Boss 获胜只取得下一阶段资格，第三阶段获胜即通关；不发放货币、物品或技能奖励。普通怪物战斗掉落不受影响。
- 击败第三阶段 Boss 后直接通关结算，不再开放任务后搜刮。

### 暂定数值

- 初始可承受 3 次战败，第 3 次战败结束试炼；具体次数待原型验证。
- 战败后免费恢复至最大生命的 100%；适用于世界探索与阶段 Boss 挑战，且仅在本次试炼未结束时执行。

### 待确认与待验证

- 治疗的具体数值、费用和使用条件。
- 验证战败免费回满是否使故意战败换取治疗成为常用策略，以及战败次数的代价是否足够。
- 本次试炼的可承受战败次数与难度适配，具体次数已列为暂定数值。
- 阶段 Boss 的模板池、随机组件规则与各阶段强度，具体内容和数值留到后续方案。
- 起始物品的具体内容、职业/血统适配与资金数值，留到最小物品库和经济方案。
- 首次通关与成就、更多难度、评分和长期奖励后续考虑，不纳入当前定稿。

## 2. 探索、卡牌与任务

本节统一维护卡牌、叠牌、警戒、生成和传送规则，不另设重复规则文档。

### 探索与回归

- 大地图按节点连接组织。世界入口免费，其他新节点首次开放消耗探索时间；已开放节点可直接免费传送重访，不逐段走回。未开放节点仍受连接、守路与必要前置限制。
- 探索时间是行动资源，不是现实倒计时；主线完成不恢复预算，货币不默认购买时间。时间不足不能开启新节点，但仍可处理已开放节点。
- 必要前置必须结构可达，不保证任意探索路线能完成。主线无法完成时认输直接结束试炼，不扣一次战败机会重开世界。
- 主线完成后可继续探索或直接回归，不必走到撤离点；回归后当前世界关闭，遗留物资不可再取。
- 世界候选展示主题、主线目标类别、资源方向及重要特殊机制，不提前揭示具体库存、随机奖励或未发现怪物配置。进入后主线目标和必要条件可查看。
- 没有独立期限的节点不因离开恶化。具体限时任务说明何种移动推进时间、期限与后果；不统一把时间耗尽设为自动失败，不把普通阅读和挪牌当作时间推进。
- 地图不提供推荐路径、已探索节点剩余机会摘要或远程商店库存。传送不是远程拾取、交付或交易。

### 暴露与操作

每个位置按下层至上层记录独立牌。仅最上层可成为可接触对象；被盖住的已发现对象保留信息，但不能直接调查、开箱、拾取、挑战或挪动。移走顶层后，下层自动翻开，只揭示信息，不自动开箱、拾取、交谈或战斗。一次移动一张，不移动整列，不以同花色或点数判断落点。未知对象不能用作承接位置。

发现、接触与合法动作分别判断。主动点击可挑战的怪物牌直接开战，独立查看配置不触发战斗。已知但被遮挡的怪物不能隔层主动点击，但可以按警戒规则主动参与战斗。箱内附属物不属于独立下层，随箱移动且不占叠高；开箱仍要求容器可接触及开箱条件满足。被箱子遮住的独立牌留在原位。

不提供撤销，已提交动作只能通过当前合法操作手动恢复摆放。尚未提交的拖拽或确认可以取消。战败回退属于失败结算，不是撤销。阅读、查看、翻牌、挪牌及普通销毁不额外消耗探索时间；具体事件可明确特殊消耗。节点不模拟角色步行距离，不因普通操作推动怪物行动或通用倒计时。

### 卡牌类型与权限

卡牌按归属分为物品、场景、怪物、角色、信息、事件六类。放下、拾取、翻面不改变类型。任务标签增加明确限制，不单独作为主类型。

| 类型/子类型 | 收入背包 | 挪动 | 主动销毁 |
| --- | --- | --- | --- |
| 普通物品：装备、材料、恢复品、普通钥匙、工具 | 可以，检查容量 | 可以 | 可以 |
| 运输任务物 | 可以，检查容量 | 可以 | 不可以 |
| 场景容器 | 不可以 | 可以，内容随行 | 可以，受保护内容除外 |
| 场景普通杂物 | 不可以 | 可以 | 可以，无收益 |
| 可移动装置、机关 | 不可以 | 可以 | 默认不可以 |
| 固定装置、机关、特殊通路 | 不可以 | 不可以 | 不可以 |
| 怪物 | 不可以 | 不可以 | 不可以，击败由战斗结算 |
| 角色：商人、委托人、普通人物 | 不可以 | 默认不可以 | 不可以 |
| 信息：线索、记录、主线必要凭证 | 调查后进记录，不占背包 | 不可以 | 不可以 |
| 事件 | 默认不可以 | 默认不可以 | 默认不可以 |

敌对人物归怪物类。场景默认只能在所属节点移动，需要运输的对象归物品类；具体特殊机制可以明确例外。可移动装置功能随牌保留，移动不重置进度。遮挡限制操作，不默认停用装置、持续效果或取消已启动事件。

事件表示活动、选择或特殊机制；默认不承接其他牌，露出不等于执行，执行前说明必要条件、代价和重要后果，进度/结果不因重访凭空重置。次数、随机、取消、领奖及战斗后果由具体事件定义，不采用统一的“先清奖励才可再次参与”等硬限制。

### 承接测试输入

采用宽松承接：物品、容器、可移动杂物及可移动装置彼此可叠放；运输任务物也可叠放，但保护权限不变。空位可以承接。固定装置、通路、角色、信息及默认事件牌不是普通落点；怪物位置属于危险放置，不是普通承接。

叠高按整个位置计算，不能由每层各自承接绕过限高。每位置3张独立牌暂为局面测试输入，不是最终数值；箱内附属内容不计叠高。容器叠放不等于容器收纳。初始遮挡关系不等于玩家承接许可，例如生成时容器可遮住线索，不意味着玩家可以向信息牌主动放物品。

背包实物放入场景后成为独立物品牌，占位置并遮挡下层。拾回须检查容量，不足则留原处，不删除其他牌、不生成临时空位。结构可解不代表任意玩家摆放都可解。

### 战斗与持久化

普通翻牌不触发主动战斗。主动点击合法怪物牌直接开战；查看通过独立入口。危险放置先确认后果，拖动经过或取消不改变摆放。战败回退本次危险操作前的摆放及携带归属，不复制实物，不回退更早调查、交易与已知信息。

销毁、放弃奖励等保留简短确认，不展示实际损失明细。销毁非空容器同时销毁剩余内容，无收益；容器遮住的独立下层不被连带销毁。销毁容器引起当前节点警戒，普通开箱、拾取、交谈和查看不默认套用此效果。

警戒确认前显示确定的总遭遇数量。确认时锁定当前已发现、未击败且满足战斗前置的怪物，从左至右、同位置上至下排序。未发现、被封印/隔离或前置未满足者不加入；已发现后再次被遮挡不清除资格。销毁后新翻出的怪物不补入本次队列。警戒不能绕过任务前置。

连战自动进行，生命延续，期间不换装、治疗、搜刮或传送。每场独立结算：首场失败恢复销毁前状态；首场胜利后销毁生效，后续失败不恢复容器、不复活已败怪物、不撤回此前奖励。任一失败停止并清除自动挑战队列，按既定世界战败规则处理，剩余怪物保留，重访不自动续战。第三败仍结束试炼。

货币/进度每场胜利立即结算；实物每场生成并留在对应遭遇，技能及采血在连战停止后处理，不在途中新增成长。普通技能仍当场学习或放弃；连战延后是明确例外，不生成秘籍。击败后的怪物退出遮挡层，未领取奖励与遭遇记录保留。

重访保留叠牌顺序、发现信息、箱内未拾取物、敌人胜负和暂存实物，不洗牌。战斗胜利解除的守护条件绑定对象身份，搬动箱子不能解除条件。回归后不能再从该世界取物。

### 奖励、合成与直接装备

战斗、任务及事件的新实物先作为来源附属奖励，不立即占场景位置；来源交互结束或怪物退出遮挡层后，未领取奖励仍保留。领取检查容量，主动放到场景后才成为独立物品牌。普通场景摆放不触发合成；只有背包内支持合成的装备自动合成，拾取可按合成后的最终占用领取。材料、恢复品等不合成或堆叠。

装备可直接进入战斗栏，也可原子替换旧件；先检查完整落点，成功才付款或转移。旧件须有合法去处，不默认放回商店或奖励来源。直接装备不触发合成，非装备物品不能借背包满进入战斗栏；失败不扣钱、不丢物、不留下半完成状态。普通领取操作不强制要求先入背包。

### 保护、生成与任务

受保护对象不可被间接销毁：容器含不可销毁内容时暂不可销毁，取出后再处理。主线必要线索不得因销毁永久丢失；调查写入记录后，其来源对象可恢复原有普通权限，不把信息牌本身改成可销毁牌。已完成记录不因实物出售、放下、场景变化而回退。可选收益不自动全部受保护，特殊事件不能默默绕过保护。

生成先定对象和关系，再排位置。简短节点不强行挪牌，普通节点提供局部取舍，关键节点用可核对模板。必要对象须有合法暴露/获取路径，不依赖随机稀有装备唯一解；结构可解不保证玩家战力、资金或全部收益。首次生成后固定，任务/事件明确改变局面不等于重生成。

首轮运输、寻人支线允许先行动后接取并追认；运输须实际持有对应对象交付，寻人按交谈记录。接取与领奖分开，不提前发奖、不重复领；特殊先接后做任务需明确说明。主线进入世界自动接取。

### 传送与范围

普通通路改为公共操作区的传送入口，不为每条连接放场景牌。新节点仍按拓扑、守路前置及探索时间开启；已开放节点可直接免费传送重访，不逐段走回。战斗/警戒连战期间不可传送。特殊封印门或机关门可保留为场景对象。主线完成后可继续探索或回归，回归后世界关闭。

### 世界生成与任务组织：已定规则

- 每个被抽中的世界均保留主线、探索、收益和回归的完整阶段流程；阶段覆盖少不等于奖励房。小型世界也应提供不依赖稀有专属组件的可利用内容，但不保证随机结果适配玩家构筑。
- 世界生成分为任务骨架、节点地图与节点内部三层。任务骨架固定核心目标、必要条件与关键人物关系，可变化任务变体及部分解决方式；地图保证必要地点与前置关系可达，可随机地点位置、连接和可选分支；节点内部保留对象身份、事件依赖及必要解法，可随机合法摆放、敌人配置与普通容器战利品。
- 普通搜刮节点允许更高随机性，关键节点采用经过设计的局面模板，不将全部剧情对象无约束打散。
- 每个世界围绕明确主线组织，支线可提供成长收益、情报或替代解法，以及人物和世界背景；不将所有可选支线作为必做前置。
- 标准世界先按两条支线组织，不要求支线一定战斗，可寻找人物、收集地图物品或交付；一条支线可跨多个节点，也可复用已有遭遇，不按支线条数强行新增战斗。
- 主线不统一要求击杀最终敌人，可采用取得目标、交涉或完成事件；完成条件明确，具体路径可随探索逐步揭示。
- 满足条件后，必要线索、唯一凭证及任务明确承诺的奖励确定获得；普通构筑收益继续随机。必要产出不依赖普通随机掉落抽取。
- 容器可以提前透露收益类别而不展示全部具体结果。开箱、挑战与任务奖励分别记录，同一份收益不重复发放。
- 搜刮采用分层收益：小容器以材料等补充收益为主，精英与世界内 Boss 对应宝箱可提供更丰厚的数量、品质或特色内容机会，不只追加廉价材料。具体分布、数量与概率待标准世界样本验证；主神阶段 Boss 仍按原规则无奖励。
- 技能与物品获取概念分开，所有容器均不产出技能，包括精英和世界Boss宝箱，不生成可携带秘籍。技能可由实际敌人、NPC、任务和事件提供，按技能学习规则处理，包含警戒连战延后决策的例外。
- 第一阶段标准世界容器的首轮奖励名额与品质分布已采用，见[标准世界分布草案](../history/2026-10-14固定推演/标准世界分布草案-v0.1.md)第7节；只确认测试供给，不证明经济或战斗平衡，其他地图及资源金额仍需验证。
- 各主题世界拥有特色装备机制、物品机制和事件机制，不只通过名称、背景或获取方式区分；特色机制参与构筑与探索，同时保持统一自动战斗框架与跨世界物品联动。具体机制及兼容边界后续制定。
- 完整主题体系包含物品生态、特色规则、技能与事件，并支持多条构筑路线，不以单一机制或一套标准答案定义整个世界。主题重点供应某些公共标签，但不独占标签；外世界物品满足条件时同样能参与对应联动。
- 同主题系列共用基础物品库，阶段版本通过品质分布、供给权重和逐阶段新增物品改变成长机会，不需要按阶段制作三套等量独立物品。高阶版本可同时提供高品质基础物品与更高起点的新特色物品。
- 基础物品通过更高品质与既有用途继续参与后期构筑；高阶新物品提供更强机会，但应保留空间、启动、配合或价格等取舍，不统一无条件替代全部基础物品。

### 主题机制的归属与持续范围：已定规则

- 装备、物品、职业与血统自带的主题机制跟随持有对象，在后续世界继续参与构筑；更换或失去对象后按其持有条件处理，不将主题特色统一限制在来源世界。
- 世界环境机制仅在当前世界生效，离开后失效；事件强化与代价必须明确标注本世界或本次试炼等持续范围。
- 特色机制使用统一的冷却、伤害、状态与公共触发框架；跨世界组件可通过公共行为联动，不要求每件物品都直接识别所有主题专属机制。
- 每个世界围绕少数核心特色组织装备、支持物品与事件，不为每件物品新增独立机制，也不为每个世界建立脱离统一框架的战斗系统。具体特色数量与内容待制定。

### 内容与验证边界

- 首批主题、装备、技能及参数见[世界与内容设计](世界与内容设计.md)；地图及牌面样本见[第一阶段设计方案](第一阶段设计方案.md)。
- 保持结构可解与结果未知的区别。节点数量、探索预算、叠高和奖励名额为测试输入，不当作最终平衡。
- 具体限时任务需核对至少一条合法完成路径；有限落点、免费传送和暂存不应变成无意义整理或往返搬运。


## 3. 自动战斗与成长持续范围

### 已定规则

- 当前战斗机制以 The Bazaar 为参考，采用物品驱动的实时自动战斗；物品通过冷却与公共触发事件形成联动。
- 角色当前生命跨战斗保留，战斗开始不自动恢复满血。
- 普通物品数值成长仅在当前战斗有效，战后清除；护盾、灼烧、中毒、控制状态及明确的战斗临时效果均在战后清除。
- 明确标注“永久增加”的效果表示本次试炼内永久成长，可跨战斗、节点和世界保留，试炼结束清除，不带入下一次试炼。
- 物品的本次试炼成长绑定单件物品，同名物品不共享提升；战斗外可通过消耗品或事件提升。
- 废止此前将普通战斗成长解释为跨战斗保留，以及将“永久增加”解释为跨试炼保留的规则。
- 战斗采用参考 The Bazaar 的沙尘暴机制推动僵持战斗结束，不采用到 30 秒直接判玩家失败的方案。
- 第 30 秒开始沙尘暴，对双方施加逐步增强的伤害，战斗继续到分出胜负；30 秒是常规战斗时限，不是硬性结束时间。
- 沙尘暴每次对双方同时施加等额伤害，忽略护盾与减伤，伤害逐次增加。
- 沙尘暴期间物品照常运作，治疗仍然有效。
- 双方同时死亡时，判定玩家挑战失败，消耗一次全局战败次数，不获得胜利奖励；执行正常战败后处理。

### 待确认与待验证

- 本次试炼成长适用的属性、获取方式与上限。
- 暴击概率的具体来源和数值；多来源伤害分配、效果取值快照与取整等实现细则留到最小战斗方案。
- 沙尘暴伤害的初始值、跳伤间隔与递增曲线；验证其是否能结束治疗构筑之间的僵持。

### 基础战斗机制：已定规则

- 单场战斗先采用玩家与一个敌方单位对战，双方使用统一的物品与被动技能框架。
- 每场开战重新计算物品冷却，不继承上场或探索中的冷却进度；常规主动物品从完整 CD 开始，被动先建立，再处理明确的开场效果。
- 攻击伤害先扣护盾，剩余伤害扣生命；物品和技能可以明确规定例外。
- 同一战斗帧攻击与灼烧共同消耗护盾时，护盾优先抵挡全部攻击，再用剩余护盾抵挡灼烧；中毒与沙尘暴按既定规则绕盾。优先抵挡是伤害类型之间的防御分配，不改变双方同步锁定、伤害后统一吸血与判死的规则。多个攻击来源共用该帧攻击抵挡结果，并按各自攻击贡献分摊，不按物品顺序抢占吸血基数。
- 护盾可在本场战斗叠加，战后清除。
- 治疗恢复生命，不超过最大生命；实际恢复的生命保留到战后。
- 最大生命上限增加时，当前生命同步增加相同数值，且不超过新上限。例如 60/100 增加 50 上限后变为 110/150；不直接回满。
- 上述补同值生命仅用于首次获得来源、消耗强化、进阶等真实新增成长；重新启用已持有来源只恢复最大生命上限，不补当前生命。当前版血统不开放自由卸下及重新装回操作，不把该防重入规则解释为新增血统切换入口。
- 战斗内临时增加的最大生命在战后清除；本次试炼成长与装备基础属性按各自持续范围处理，不因这一规则自动清除。
- 最大生命上限降低时，当前生命不得超过新上限；战后清除临时最大生命时也执行此规则。
- 灼烧采用可叠加、定时造成伤害并逐渐衰减的状态，护盾可抵挡灼烧；具体跳伤间隔、衰减和护盾减伤比例待数值阶段细化。
- 中毒采用可叠加、定时造成伤害的状态，绕过护盾，默认不自然衰减；跳伤间隔待数值阶段细化。

### 冷却控制与暴击：已定规则

- 加速提高指定物品的自然冷却推进速度，减速降低推进速度；倍率为暂定数值。
- 同类加速或减速重复施加只延长持续时间，不继续叠加倍率；加速与减速同时存在时互相抵消。
- 充能立即推进指定物品的冷却若干秒；达到终点后成为就绪状态，最早下一战斗帧释放；超过终点的充能不储存为下一次释放。
- 冰冻暂停指定物品的自然冷却与释放，解冻后继续；重复施加冰冻时，累加剩余冰冻时间，不丢弃不同来源的控制效果。
- 冰冻期间允许充能，但物品只能解冻后释放。
- 当前加速样本随机挑选己方另一件主动物品，排除自身；随机抽取概率与其他有效目标细则留到最小方案确认。
- 当前最小方案中的敌方减速、冰冻效果随机挑选对方一个物品作为目标，不按物品位置或基础 CD 优先选择；具体抽取范围与概率后续细化。
- 每次物品释放统一进行一次暴击判定，本次伤害、治疗、护盾和施加的灼烧/中毒量共用该结果；倍率为暂定数值。
- 灼烧、中毒施加后，持续伤害不再单独判定暴击，避免重复放大。

### 公共事件与同时结算：已定规则

- 主动物品实际释放才产生“使用物品”事件；冷却推进和被动触发不等于使用主动物品。
- 物品可以自带被动效果，与独立学习的被动技能分开；当前护盾样本采用“当使用武器时，充能此物品 1 秒”。该被动监听己方武器的使用事件，只为拥有此被动的物品自身充能，不要求另学技能或选择护盾目标。
- 区分攻击、灼烧、中毒和沙尘暴等伤害来源，“攻击时”不由所有伤害统一触发。
- 治疗记录区分计算治疗量与实际恢复量：计算治疗量为本次治疗效果经修正后的数值，实际恢复量受最大生命限制。
- 满血治疗仍计算治疗量，可参与治疗统计与治疗触发；只是不使当前生命超过上限，不因实际恢复量为零而取消治疗事件。
- 同一时刻双方已经就绪的物品同步结算，再判断死亡，避免一方固定先手。
- 独立触发事件分别结算并累加充能；例如同帧同时施加剧毒和灼烧，各触发 1 秒充能，目标合计获得 2 秒充能。
- 不采用“整条即时触发链中同一被动最多一次”的去重方案来吞掉上述独立事件；禁止重复处理同一个事件，与允许不同事件累加是不同问题。
- 连锁按战斗帧推进：本帧发生的独立事件全部处理，充能累加；被充能到达冷却终点的物品，最早在下一战斗帧释放。
- 新释放产生的事件继续按逐帧规则推进，允许不同端口累加及持续连锁，不在同一战斗帧无限递归。
- 战斗帧表示战斗结算时间步，不等同于画面渲染帧；具体时间步长待数值与实现阶段确定。
- 超过冷却终点的充能不储存为下一次释放。

### 同一战斗帧的结算顺序：已定规则

1. 确定行动：双方本帧已就绪且未被冻结的物品锁定本次释放。
2. 防御与恢复：先处理生命上限增加、护盾和治疗。
3. 伤害：处理双方攻击、持续伤害和沙尘暴，记录攻击实际造成的生命伤害，不提前判断死亡。
4. 吸血与死亡：双方按本帧合法攻击生命伤害统一计算吸血并恢复生命，之后再判断死亡；不以固定先手顺序让一方先恢复。
5. 连锁：战斗仍继续时，处理产生的触发事件并累加充能；新就绪物品最早下一战斗帧释放。

- 本帧新施加的冰冻不取消已经锁定的释放，从下一战斗帧起阻止行动。
- 新施加的灼烧、中毒从下一次对应跳伤时生效，不立即额外跳伤。
- 同帧治疗可以救命；例如当前生命 60、治疗 30、受到伤害 80，结算后剩余 10，仍须遵守治疗不超过最大生命的规则。
- 吸血可在同帧死亡判断前救命，不能复活已结束战斗的角色。伤害后生命中间值不能先截断为0再追加吸血，否则微量吸血会错误抵消巨额超杀；计算最终生命后再按正常胜负处理。
- 吸血与死亡阶段后若本场战斗已经结束，不再执行本帧后续连锁；双方同时死亡按已定失败规则处理。

### 冷却控制与暴击：暂定数值

- 持续伤害已采用测试值：灼烧、中毒每秒跳伤，每层造成 1 点伤害；灼烧每跳后减少 1 层，护盾按 1:1 抵挡；中毒绕过护盾且不自然衰减。具体物品的首轮测试配置见《游戏最小战斗与经济方案.md》。

- 加速时自然冷却推进速度为 2 倍，减速时为 1/2；二者同时生效时推进速度为正常速度。
- 暴击放大倍率为 2 倍。
- 沙尘暴已采用测试曲线：第30秒首次伤害为5，之后每秒为10、15、20……；四档品质物品测试表见《游戏最小战斗与经济方案.md》。
- 战斗结算时间步长待定，逐帧连锁不依赖画面渲染帧率。

## 4. 当前范围、试炼结束与战斗外强化

### 已定规则

- 第一版聚焦单次试炼闭环，不做跨试炼物品保留、仓库与从仓库携装入场。
- 每次试炼提供基础起始物品和资金；起始物品按所选职业/血统配置，具体内容后定。
- 当前最小样本采用开局一件青铜长刀、100/100生命与30货币；长刀占2格、CD4秒、伤害12，作为可调整测试基准。职业与血统的其他可选起始配置另行制定。
- 通关、整次试炼失败或认输后，本次试炼的物品、货币、已学技能和成长不带入下一次试炼。
- 本次试炼尚未结束时，战败保留已有装备与背包；回归后仍可携带物品进入后续世界。
- 主神空间整备保留购买、整理、合成、交易和治疗功能；不提供跨试炼仓库存取。
- 消耗品或事件可在战斗外强化某一件物品，强化持续到本次试炼结束；同名物品不共享提升。
- 主神商店可出售武器、角色生命与血统数值强化消耗品，货币用于取得实物，战斗外使用后消耗；强化“永久”仍只指本次试炼。与自动战斗装备、点数升品质和身份进阶分开定义，具体测试输入见[生命尺度与货币成长](世界与内容设计.md)。
- 角色、职业与血统的成长持续范围使用统一术语，“永久”仅指本次试炼，不默认采用跨试炼数值成长。
- 首次通关与成就、更高难度、评分及长期奖励后续考虑，不纳入第一版核心规则实现要求。
- 当前不落实通关后额外发放可跨试炼保留的物品或强化消耗品奖励。

### 待确认与待验证

- 起始物品与各职业/血统的具体配置、基础资金数值。
- 用于强化的消耗品来源、事件出现位置、提升成本和上限。
- 强化物品出售、丢弃时的处理；合成继承见战斗栏与背包规则。
- 验证单次试炼中的构筑、阶段推进和通关本身是否足够支撑重复游玩。

### 货币强化与身份生命

- 角色基础、血统及点数/货币强化共同提供最大生命，允许中后期达到数千。当前阶位贡献读取当前值，不把各阶位相加。
- 真正新增最大生命时同步增加当前生命相同数值；移除来源按新上限夹取，重新启用已有来源不补血。独立角色成长不随身份替换丢失，血统成长归对应血统。
- 强化消耗品逐件占空间，不堆叠、不合成，战斗外使用；购买不自动使用，无合法目标不消耗。无额外“一试炼一次”硬上限，受库存、价格、刷新和容量限制。
- 主神强化消耗品独立库存，购买留空、付费刷新，不保证指定商品；世界来源按主题明确，不默认每家店卖全部身份精华。
#### 武器强化继承

- 淬锋石只增加所选单件武器的已有攻击，不为护盾、治疗或没有攻击效果的物品新增攻击。不增加中毒、蓄势层数、CD缩短或同名其他武器。
- 记录在该单件的本次试炼成长中，战后保留；本场临时成长仍战后清除。效果成为攻击数值的一部分，释放暴击按正常规则放大，不额外再判一次暴击。
- 两件合成时两件本次试炼成长加总继承，品质基础属性另按新品质读取；点数升品质不清除成长，也不按新基础值比例再次放大该固定加成。
- 出售、销毁或留在已回归世界时随物品失去；强化不额外提高售价，不通过强化、合成后倒卖回收强化成本。

#### 血统强化边界

- 血源精华和凝血精华要求当前持有血族；未持有时不能使用，但可占背包保留。其他血统未来定义自己的对应消耗品，不提前为未设计身份填写数值。
- 强化记录绑定该血统，事件替换后旧加成失效，本次试炼结束清除；当前版没有自由卸下或换回入口。血源精华增加的生命不受血族阶位基础生命变化重复放大。
- 凝血精华是独立固定中毒加成：最终血统中毒加成为“已采种类×当前阶位系数＋已消耗精华累计值”，不增加种类记录，不冒充再次采集，也不因进阶把精华值额外乘一遍系数。
- 凝血精华不提高每层跳伤，不让普通武器凭空施毒，不提高吸血比例。本轮暂不出售无限叠加吸血比例的消耗品，避免未定义的100%及以上吸血边界。


## 5. 战斗栏与背包

### 已定规则

- 第一版使用容量制，通过物品占用空间进行取舍；形状与旋转拼图暂不作为第一版规则。
- 第一版战斗栏与背包容量固定，不设置容量成长。
- 战斗栏容量已确认采用标准10格，参考大巴扎的规模；物品按大小占用格数。背包容量独立采用测试值10点；材料与恢复品逐件占1点。
- 所有物品均不作数量堆叠，包括装备、材料和恢复消耗品；重复件逐件占用空间。节点探索卡牌的覆盖与有限承接不是物品数量堆叠，不改变背包容量计数。
- 战斗栏与背包具有独立容量，只有放入战斗栏的物品参与战斗。
- 背包存放备用装备、材料、消耗品与战利品，按物品大小占用容量。
- 从背包装备到战斗栏后，物品只占战斗栏空间，不重复占用背包容量。
- 卸下物品须有合法去处，可入背包或按探索规则放到当前节点；也可先替换、出售、消耗或丢弃腾位，不能自动销毁旧件。
- 领取可选择背包或直接装备；按完整操作及合成后最终容量校验，替换旧件须有合法去处，失败不转移或扣款。
- 空间调整不意味着随时允许出售或消耗，仍需满足对应操作的地点与使用条件，具体规则待定。
- 携带实物可在当前节点合法位置暂存，按第2节保留状态，不占携带容量但占节点承接空间；情报与唯一必要主线凭证不占普通背包。

### 职业与血统：已定规则

- 职业与血统各有一个独立槽位，不占战斗栏或背包容量。
- 职业与血统主要提供被动规则，通过公共机制与装备联动。
- 试炼开始前可从当前可用内容中选择职业与血统；跨试炼解锁进度后续考虑。
- 试炼内可通过事件获得或更换职业与血统；替换后旧被动失效。
- 职业与血统的本次试炼成长记录在对应职业或血统上，不因本次试炼内替换而清除；试炼结束清除。
- 职业与血统采用基础能力、进阶收益和成长条件的结构，不限于开局小被动；可提供百分比加成与明确的数值成长，并与装备、技能共同构成成长体系。
- 血统本身可提供最大生命，角色也可通过货币购买生命强化消耗品；不把生命成长限定为主神点数兑换。最大生命尺度允许中后期达到数千，旧100生命样本不作为数值上限；具体生命、伤害、恢复与沙尘暴应联合校准。
- 血统专属数值强化消耗品可由对应主题世界及主神商店提供，成长绑定该血统，事件替换后旧血统加成失效、本次试炼结束清除；独立角色生命强化不因换血统清除。当前版不提供自由卸下血统或把旧血统重新装回的操作，各血统效果与商品范围逐项定义，不默认当前世界供应全部身份强化。
- 进阶使用独立阶位，不直接套用装备品质。系列世界可通过事件、挑战或交易提供特色进阶机会，主神空间提供明确的通用途径与成本；阶数、价格及各身份的成长内容待制定，不代表所有进阶已实现。
- 血族百分比吸血只由明确的攻击伤害触发，以攻击实际造成的生命伤害为基数；不包含中毒、灼烧、沙尘暴、被护盾吸收的伤害或超杀。按伤害类型而非所有扣血效果判断，不自动把技能的任何直接扣血归入攻击；技能明确产生攻击伤害时按同一分类规则处理。
- 同帧多来源伤害按抵挡后伤害占比分摊实际生命损失。以本帧防御与治疗后、伤害前的非负当前生命为可损失基数；各来源先按伤害类型处理护盾与合法减伤，再对总生命伤害使用统一比例：实际生命损失为可损生命与总伤害的较小值，各来源归属为该损失乘自身抵挡后伤害占比。中毒、灼烧、沙尘暴同样参与实际生命损失分摊，但其份额不产生吸血；多个攻击来源也按自身贡献分摊，不按物品摆放或处理顺序抢占基数。
- 例如敌方剩10生命，同帧抵挡后攻击80、中毒20，则攻击归属8点实际生命伤害、中毒归属2点，10%吸血恢复0.8。分摊仅用于归属统计与吸血基数，不截断实际伤害结算的生命中间值；吸血恢复不回写该帧已锁定的伤害基数或生成第二轮吸血。
- 吸血恢复生命不产生治疗事件，不触发回春护体、稳压回路、瘟血回响等监听治疗的效果，也不受医者等治疗量加成影响；明确的吸血比例修正仍有效。保留小数计算，恢复后不超过最大生命，多次攻击不能重复计算同一份实际生命损失。首轮比例见下表，旧固定治疗测试值不能替代新内容。
- 吸血按第3节在双方伤害后、死亡判断前统一结算，不将“不产生治疗事件”等同于“不恢复生命”。多来源实际生命伤害归属采用上述占比分摊；公共规则确认不代表工程接入或完整战斗验证通过。
- 当前对应血统可在胜利后主动采血，每遭遇最多一次，同种不重复增长；生物类型决定资格，不按装备主题判断，纯机械默认无血。采血不消耗探索时间、不重置战利品，记录归对应血统、不占背包；警戒连战停止后才采集，不在途中新增成长。种类定义仍需按具体内容制定。
- 血液成长提高己方中毒物品每次施加的中毒量，不直接提高每层跳伤或修改敌人已有层数。已完成采集不因重访、重复挑战或战败产生重复收益。
- 百分比吸血、收集成长与多物品联动可形成显著强度提升，不统一限制为微小加成；需联合验证供给与成长效率。事件替换身份时旧加成失效，对应成长记录仍保留，但保留记录不代表当前版开放旧血统的自由重新装备入口。

| --- | --- | --- | --- |

| 第一进阶 | 第一阶段整备 | 15% | +2 |
| 第二进阶 | 第二阶段整备 | 25% | +3 |

### 重复物品合成：已定规则

- 两件同名、同品质物品可合成一件，品质提升一级。
- 非战斗状态物品进入背包时自动合成，不额外收取费用；只查找背包候选，按显示位置从左到右、从上到下优先选择。进入战斗栏与同栏挪位不触发，不提供手动合成入口。
- 产物替换优先候选位置，允许继续匹配新品质并连续升级。容量按完整合成后的最终占用校验，满包可接收最终能容纳的重复件；失败整次回退。购买到战斗栏不通过背包，也不触发入包合成。
- 合成产物的基础属性按新品质计算，不将两件基础属性再次加总。
- 非战斗状态合成时，战斗内临时成长已清除，不参与合成继承；两件物品的本次试炼成长加总继承，独立于新品质的基础属性记录，试炼结束清除。
- 合成消耗两件原物品，仅保留一件产物；最高品质物品不再通过重复件提升品质。
- 最低起始品质不改变同名同品质两件合一的规则；黄金起步物品用两件黄金合成钻石，不提供不存在的低品质合成路线，也不能用其他同类物品替代。高阶直接获取与早期逐步合成并存，已获得的本次试炼成长仍按既定规则继承。

### 品质与物品价值：已定规则

- 品质默认保留物品核心行为，通过伤害、频率、持续时间、触发收益与成长效率等参数强化既有用途；少数高品质可明确增加效果，不要求每档新增机制。
- 同一物品各品质复用卡面，以边框、数值与效果说明区分。品质参数可涉及频率，具体制作规范与现有固定冷却约束的同步待后续处理，不代表已有流水线支持。
- 同品质不代表不同物品强度相同。高阶特色物品提供更高起点或上限，同时保留空间、启动、配合或成本等取舍；基础物品可凭体积、速度、触发次数等用途继续参与后期构筑。

### 暂定数值

- 物品分小、中、大三种大小，分别占用 1、2、3 点空间。

### 待确认与待验证

- 验证战斗栏固定10格、背包固定10点能否形成有意义的空间取舍。
- 消耗品与材料的逐件空间占用；已确认不堆叠。
- 职业与血统的初始可选内容、事件获得方式，以及更换时本次试炼成长的处理；解锁进度不纳入当前范围。
- 品质体系采用青铜、白银、黄金、钻石四档，但每件物品可设最低起始品质，不强制拥有全部四档；仅为该物品支持的品质制定数值，不套用统一倍数。具体属性、效果变化与最高品质表现待数值验证。
- 最低起始品质规则与现有物品制作指南、Excel 校验及固定四档预览存在差异，后续需同步制作规范与工具；本轮不代表已有流水线支持缺失低品质档位。
- 快速交换与整理方式。
- 初始物品的装备操作，以及背包与战斗栏容量校验。

## 6. 商店与经济

### 已定规则

- 世界内与主神空间均提供商店，采用随机商品和付费刷新。
- 世界商店商品池以当前世界物品为主；主神商店混合各世界物品，品质概率随阶段变化。
- 阶段版本同时控制可供物品范围、最低起始品质约束与实际品质分布，不将物品阶段准入与品质视为同一属性。更高阶段可供应早期基础物品的高品质版本；具体池与权重待制定。
- NPC 商店具有各自的商品倾向，例如兵器铺偏武器、医馆偏恢复、武馆偏技能，具体权重后续设计。同一节点多家店分别保留独立库存，分别付费刷新，不因刷新一家店而重置其他店。
- 技能购买条件视 NPC 与商品设定，可包含挑战或任务要求；满足购买条件并支付价格后立即学习，不生成可携带技能载体。同名技能沿用既定学习、替换与合成规则。
- 不设置定向刷新、指定购买或关键物品保底作为必要机制。
- 商品买走后留下空位，不自动补货；付费刷新重新生成整批商品。
- 可以免费锁定整批商品，刷新前需要解锁。
- 重访商店保留原有商品与购买留下的空位；离开、重访或战败不触发免费刷新。
- 刷新费随该店成功刷新次数递增，各店独立计数。世界店新世界初始化、主神店新阶段整备初始化时重置，重访、购买、锁定及同阶段战败不重置；失败刷新不扣钱或增加计数。具体阶梯作为可调整测试参数维护。
- 库存已确认：世界店首次进入所属节点时初始化；主神店每个新阶段整备期初始化一次，同阶段重试保留。锁定仅针对当前库存，不跨新的整备期保留商品。
- 节点中的商店是交易入口，不作为需要挪走才能访问下一层的普通物品卡；商店付费刷新不重新生成普通敌人或容器。
- 在商店出售物品，回收部分价值。
- 每件物品按其支持的品质分别制定标准价，大小与品质不是唯一价格依据；旧同大小同品质统一价格仅保留为旧版测试样本，不作为完整规则。
- 当前出售回收统一为对应品质标准购买价的 50%；具体标准价与非整数价格处理留到经济表，不因该规则让技能可出售。
- 本次试炼额外成长不默认提高售价；定价需检查购买、合成、出售是否产生稳定倒卖套利。
- 玩家可通过支线任务奖励、怪物货币与物品掉落、掉落材料买卖积累资源，再购买装备与技能获得基础战力；材料占用随机掉落名额，不默认在装备或技能掉落之外额外产出。材料的其他用途暂不制定，具体来源、数量及定价待定。
- 交易货币主要来自搜刮、战斗、出售与任务，用于装备、恢复品、技能、商店刷新及明确对象消费；任务点数主要来自主线、支线和明确额外目标，用于确定性成长。具体项目明确所需资源，不统一要求同时支付两种资源。新节点开放使用探索行动时间；主神空间治疗当前暂不收费。
- 经济体验仍采用偏紧的资源压力：普通战斗、支线与材料出售支持基础战力和消费，主线奖励支持主神整备。大量刷新与全面补强争夺资金，广泛探索争夺时间；旧付费探索经济曲线不直接作为新规则验证结果，具体收入、时间与消费需重新验证。
- 试炼货币跨世界保留；本次试炼结束时剩余货币清零，不带入下一次试炼。
- 任务点数跨世界阶段保留，本次试炼结束清零，不增加跨试炼数值成长或仓库。
- 每次新试炼提供基础起始资金，当前最小样本采用30。
- 战斗外强化可通过消耗品、事件与主神兑换进行，持续范围明确；本次试炼强化与未使用消耗品随试炼结束清除。

### 主神兑换与回归成长：已定规则

- 主神空间提供身份进阶、角色强化、持有物品升品质与已学技能升品质，为探索所得提供确定性消费端；取消单件物品直接追加数值的独立兑换项目，其数值可通过品质、自身机制、身份及其他成长线提升。不将任意指定兑换全部关键装备作为通用必要功能。
- 上述取消仅针对独立的点数直接加单件数值项目，不禁止货币购买强化消耗品。永久强化记录、合成继承与实际供给遵守物品成长和库存规则，不恢复指定兑换关键装备。
- 主神强化优先深化已有路线，同时提供基础容错投入；常规完成主线后应有机会获得明显提升，积极完成支线和携回高价值物资可支持更多投入。需防止通用属性投资无条件优于物品与身份投入。
- 兑换项目可随阶段开放更强档位。每项明确价格、效果、持续范围、次数限制与是否递增，不统一允许无限购买；具体兑换菜单与数值待制定。
- 主神使用任务点数提升持有物品与已学技能品质，每次提升一级、逐级支付；第一阶段整备上限白银，第二阶段黄金，第三阶段钻石。价格随目标品质提高，可提供额外软限制，但不替代阶段硬上限；具体各项价格待制定，不突破对象支持品质范围。此上限不降低已获得的高品质物品，也不将黄金起步物品降为白银。
- 兑换升品质与重复合成是不同操作；同名同品质两件自动合成不受主神兑换阶段上限约束，可在早期获得更高品质，最高仍为钻石。不将兑换上限扩大为全部持有品质上限。
- 身份进阶、角色强化与物品技能升品质主要竞争任务点数，货币用于购买和商店刷新；首轮不为升品质叠加货币支付，不开放点数与货币自由互换。
- 面向重复游玩，兑换条件可成为玩家积累的经验；界面提供当前对象品质、实际价格、可兑换状态与必要结果，不堆叠反复教学、全档条件预告或冗余解释。少量复杂效果可按需查看，不以减少文字为由隐瞒成本或结果。
- 回归强化后的优势应真实存在，不因玩家消费而动态补偿阶段对手。阶段 Boss 按原规则预先生成、配置与加成固定，下一阶段使用预先设计的更高压力。
- 同阶段 Boss 重试保留兑换状态，不重复领取奖励、不恢复已用购买次数。本次试炼结束时点数、兑换强化和进阶清除。

### 主神兑换：待确认与待验证

- 先确定标准世界的敌人、资源与典型访问分布，再由实际收入机会反推货币、任务点数和兑换价格。早期讨论提出的三阶段收入及价格表不直接采用，不因血族能力值获认可而自动生效。2026-10-14的新[武道三阶段成长骨架](../history/2026-10-14固定推演/武道三阶段成长骨架.md)提供当前可调整模型输入，包含消费竞争与失败证据，仍不代表完整经济定稿或工程接入。
- 主线、支线与额外目标的点数供给，各项目具体资源、价格、阶位和效果。
- 身份进阶、角色强化、物品升品质、技能升品质的消费竞争与成长后战力变化。
- 各项目具体点数价格、身份阶位上限、角色强化重复次数与跨阶段次数刷新等边界；验证重复合成可突破兑换阶段上限时的提前成型收益与供给频率。

### 战斗与掉落：已定规则

- 怪物与玩家使用相同的物品组合和公共战斗机制，怪物通过其配置形成战力，不另设脱离物品框架的独立战斗系统。
- 高阶段敌人可使用更高品质、完整联动、高阶组件、技能、匹配阶段的生命与必要强化；不主要依靠低阶装备的隐性巨额倍率制造难度。额外强化可保留，具体强度仍需与玩家完整成长体系联合验证。
- 阶段 Boss 允许装备技能联动、职业血统进阶、明确成长记录与阶段数值强化共同构成压力，不要求只依靠更多复杂物品机制提升难度。加成在战前可查看，按阶段与难度预先生成，不根据玩家构筑临时补数值，重试不变；掉落不继承身份成长或敌人额外强化，阶段 Boss 仍遵守无奖励规则。
- 普通怪物战斗胜利奖励采用“货币 + 随机掉落物”的结构，掉落物可以是装备、技能或材料；材料与装备、技能竞争随机掉落名额，战败不产生奖励。阶段 Boss 不掉落货币、物品、技能或材料。
- 敌人关联的必要任务钥匙或凭证按任务条件确定获得，与普通随机战利品分开记录；例如必须取得的守卫钥匙不因随机掉落未抽中而缺失，武器仍按普通掉落规则抽取。
- 掉落方向由世界主题与敌人类型共同影响；装备与技能仍从该怪物实际使用的配置中抽取，战前配置提供潜在收益线索。材料的掉落来源另外制定，不要求材料作为主动物品放入敌方战斗栏，也不据此允许掉落敌人未配置的装备或技能。
- 掉落物品保留对应品质，但不复制怪物的额外强化数值。
- 不保证掉落玩家当前构筑需要的组件，不直接继承敌人战斗中的强化数值。
- 强敌提供更高的掉落品质或数量，具体概率与数量待定。
- 货币直接入账，不占背包；实物掉落由玩家选择拾取，按对应大小占空间。
- 技能全部设计为被动效果，通过属性、公共事件和触发规则参与构筑。
- 技能供给采用跨阶段共享基础内容与阶段新增内容，支持最低起始品质；高品质基础技能延续原路线，高阶技能提供更强或更专门的联动。强技能应有相应获取成本或条件，不将全部强技能作为免费附加数值沿途发放。
- 第一阶段武道常规技能池先采用越战越勇、回春护体、磨锋入微及白银起步的凝息破势；火势护体保留火油精英等明确来源，不作为武馆常规主池。破阵先机优先留给中后期，其他世界新增技能不直接全部混入武道常规供给。新增候选具体参数及供给价格继续按[世界风格测试技能库](世界与内容设计.md)讨论验证，不将选定供给范围等同整体数值已通过。
- 首轮构筑验证至少覆盖快速武器与暴击成长、武器护盾联动、攻击吸血与血液中毒成长三类方向，不假定同时取得全部核心装备和技能。
- 技能不可转化为物品，不生成秘籍、卷轴等可携带载体。
- 普通技能掉落当场学习或放弃，不作为实物；警戒连战为例外，在连战停止后逐项处理，不在途中新增技能成长。
- 不采用“主动技能放入战斗栏”或“保留技能卷轴供下一次试炼使用”的方案。
- 已学技能不设置技能槽位和数量上限，全部生效；同名技能效果不重复叠加。
- 获得更高品质的同名技能并选择学习时，替换已有低品质技能。
- 低品质同名技能不降低已有技能品质，不与高品质技能合成；放弃不补偿货币。
- 技能合成或高品质替换保留玩家已经获得的本次试炼成长；怪物自身额外强化不继承。
- 普通世界战斗随机奖励已采用测试权重：70%从实际配置中可掉装备／技能条目等概率抽取，30%为一份材料；配置分支无合法条目时改为材料。具体标准价格、品质供给与首阶段收入见《游戏最小战斗与经济方案.md》第6节。
- 同名、同品质技能可以合成，沿用重复物品的两件合一件、品质提升一级规则；学习第二份同品质技能时进行合成，不将重复技能转为可携带物品。
- 最高品质技能不再通过重复技能提升品质，同名效果仍不重复叠加。
- 已学技能在本次试炼跨战斗、跨世界保留，试炼结束清除；其明确标注“永久”的成长也仅持续到本次试炼结束。

### 技能表达与公共队列

技能支持常驻修正和事件触发；使用“生效方式、事件/条件、目标、动作、参数、持续范围”表达，不执行说明文字。规则定义与运行状态分离，具体技能可扩展新机制，不能仅新增名称即宣称已支持。



| 边界 | 规则 |
| --- | --- |
| 生效方式 | 支持常驻修正和事件触发两类规则；常驻修正不要求触发事件 |
| 定义与状态 | 定义保存规则和品质数值；触发次数、冷却、临时成长等属于运行状态，不回写共享定义 |
| 表达结构 | 使用“生效方式＋事件／条件＋目标＋动作＋参数＋持续范围”；说明文字不是可执行规则 |
| 扩展方式 | 已支持机制可以组合；新事件、目标、动作或组合结算能力须先实现并验证，仅新增名称不使其生效 |
| 品质 | 青铜、白银、黄金、钻石只改变数值，不改变触发、目标和效果结构 |
| 事件语义 | 使用护盾效果、获得护盾、护盾受到伤害是不同事件，不能统称“触发护盾” |
| 目标选择 | 每条规则明确己方／敌方、筛选范围、数量、选择方式及是否包含来源；无合法目标时不执行 |
| 时间与充能 | 复用现有战斗时间单位；充能减少剩余冷却，最低为 0，多余充能不自动转换成额外使用 |
| 持续范围 | 区分常驻修正、本场成长、本次试炼成长，并明确重置时机；常驻加成不能每场重复累加到基础定义 |
| 连锁 | 技能效果可以触发其他物品和技能；每个固定战斗逻辑步内，每个实例上的每条效果最多触发一次，多余触发排队；目标与数值入队时确定 |
| 展示与统计 | 说明与实际配置一致，效果来源可追溯到技能；同一贡献不得重复统计 |

本场成长战后清除；明确属于本次试炼的成长在技能替换、合成后保留，试炼结束清除。物品流水线已支持的机制不自动视为技能配置能力。



已确认的随机与连锁边界：

- 随机选择允许重复选中同一目标。
- 无合法目标时仍消耗触发次数；是否消耗触发冷却尚未确认。
- 技能连锁可以触发其他物品和技能。同一固定战斗逻辑步内一个词条最多触发一次，多余触发进入队列等待，不直接丢弃；不使用画面渲染帧计数，避免帧率影响战斗结果。
- 一个词条指具体物品或技能实例上的一条效果；相同词条在不同实例上分别计数。
- 排队触发的目标与数值在入队时确定，执行时不重新选择目标或读取新的效果数值。
- 后续统一制定全局触发与效果术语，供物品和技能共同使用；暂不继续逐个定义示例。

#### 队列与循环规则

以下由物品和技能共用：

- 队列按入队先后执行；同一步的旧队列优先于新触发，仍遵守每实例每效果每步最多触发一次的限制。
- 同时触发采用稳定顺序入队，双方交错处理，不随机排序；具体稳定排序键与交错方式待实现前明确。
- 入队锁定的目标不存在或不再合法时，该次效果失效，不重新选目标，不返还触发次数。
- 已入队效果不因来源物品移除或技能替换而取消，继续使用入队时快照。
- 战斗结束立即清空未执行队列，不带入下一场，不允许排队效果复活已结束的战斗。
- 循环触发是允许的玩法，不在规则层禁止持续循环或增殖循环。单步限频限制执行速率，不要求连锁最终自行终止。
- 设置运行时保护上限。达到队列保护上限时明确报错并终止本场，记录触发链；不静默丢弃触发，不将本场计为正常胜负。保护属于技术安全措施，不作为技能平衡规则。

保护阈值、计量方式及异常终止后的恢复流程尚未制定，不将允许循环误写为无限队列或无限计算资源。

#### 常驻加成与待定细节

- 已有攻击数值加成不为纯护盾/治疗物品新增攻击；新增攻击效果须明确声明，非武器附加攻击不自动改变标签。
- 无合法目标仍消耗触发次数；是否消耗技能自身触发冷却尚未确定。稳定排序键、双方交错细节、技术保护阈值及异常恢复流程仍待确定。
- 内容参数及祭盾毒咒的专属支付规则见[世界与内容设计](世界与内容设计.md)，不把该技能的代价机制强制推广到全部事件或技能。


## 7. 当前范围与后续重点

当前仅推进规则与内容设计，不进行工程接入。旧原型、模型和验证结果保留原范围，不能作为当前规则全部实现的证明。测试版数值偏弱不阻塞，参数可在正式迭代调整。

接下来按完整模块推进：
- 职业与血统的基础能力、进阶收益、成长条件与替换取舍。
- 武道、赛博、诡异的具体特色事件和探索机制，不预先扩张公共硬限制。
- 身份、技能、装备及生命投资的整备菜单与消费竞争。
- 后两阶段的任务局面、敌人联动及资源机会变化，不仅增加数值。
- 完整随机供给下正常成长、弱掉落、连续战败和真实携带消费推演。

公共机制的尚未确定细节：技能无目标时是否消耗触发冷却，队列稳定排序/双方交错方式、技术保护阈值及异常恢复流程，全局多重使用时序。具体数值、效果上限及来源概率见内容设计，不将未决定事项写成已定规则。

跨试炼携物、仓库、长期数值成长、成就、评分、更多难度与长期解锁继续延后；如启用需另行审议。
