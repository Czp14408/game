## 世界与主线

武道“商队失踪案”：入口明确任务，03取得商队记录，05凭记录完成营地通行准备，06击败截货头目后完成。04守路者只封锁04-05；可从12-17-15绕行，但03和05仍必要。

赛博“失电工区”：入口明确任务，03取得停电记录，05完成重启权限，06执行系统重启事件后完成，不设置必须击败的最终任务敌人。04封锁04-05的巡逻者允许绕行，但不免除权限记录。重启作为本任务明确事件，不依赖电池、彩票或随机稀有设备。

两个世界各有运输、寻人两支线，02接受与交付。11为受保护任务物，12交谈记入寻人状态；可以先做后接。寻人基本条件不是付费医疗，医疗事件只提供额外机会。

## 布局模板应用

03可使用线索/容器/杂物的初始遮挡链，但保留合法移动路径；不把受保护记录作为销毁容器时会丢失的箱内物。11可采用受保护货箱模板，背包满仍能搬动箱子，不强迫销毁任务物。10/16明确标出精英及其箱子，未发现怪物不通过警戒数量偷泄露。18可放已发现敌人及被杂物遮住的其他敌人，移牌发现与销毁警戒之间形成选择。

交易角色、必要权限和信息牌不作为玩家承接点。摆放随机前先固定身份、守护与任务关系；同一对象不能既算任务容器、又重复领取一个随机容器奖励。没有必要挪牌的服务节点保持简短，不把所有角色盖起来制造操作劳动。

## 路线与任务检查

主线优先：开放01/02/03/04/05/06，先完成调查及准备。武道必须战胜头目，赛博完成重启；赛博不必打最终任务战斗，但回归后仍要面对阶段对手。

正常探索：在主线路径外加入07/11/12/08，带包、找到人物，再传送02交付；寻找人物可先做后接。主线前置不依赖这两支线。

深入：正常探索另加09/10，保留任务末端所需开放预算，精英胜利不是自动完成主线。清空时间后若已开放必要地点，仍能处理主线；不能看到时间0就直接判负。

绕行：03调查后从02/07/12/17/15进入05/06。未击败04不开放04-05，但不阻止已开放地点传送或合法其他首次连接。传送不是直接把未开放06点亮。

## 阶段外衔接

回归不自动恢复生命，主神可主动免费治疗。第一阶段对手来自公共武道/赛博/混合池，与所选世界无定向匹配；装备与技能随机，职业血统按模板固定。主线非战斗路径不等于免除阶段挑战，也不承诺赛博必定比武道容易。

当前方案可用于下一轮规则推演；不把世界牌面表、手工路线和旧工程检查合并称为可玩验收。


## 边界局面核对

以下保留必要的结果摘要，不另设重复规则或逐步讨论文档。

| 样本 | 核对结果 |
| --- | --- |
| 受保护货箱、线索与满背包 | 保护阻止销毁但不禁止搬动；移动容器可揭示独立线索，记录不占背包 |
| 已知、隐藏及隔离怪物 | 警戒只纳入确认时已知合法怪物，新发现不补队；知识保留可使下次队列变化，不是重生成 |
| 部分领取后销毁首败 | 只恢复本次危险操作前的剩余内容，不复制已领物品或回退此前合成 |
| 直接装备与原子替换 | 背包满但战斗栏有空间可领取；旧件须有合法去处，失败不扣款或丢物 |
| 持续装置被遮挡 | 功能不默认停止，但不能隔层操作；具体接线或时序由该机制定义 |
| 已知但被遮挡的怪物 | 不能主动隔层点击，可通过合法警戒主动参战；胜利不连带销毁其上遮挡 |
| 任务追认与传送 | 运输须实际持物交付，不远程取物；寻人追认记录，回归后世界关闭 |
| 警戒途中完成主线 | 进度保留，但不因此中断连战或允许战斗中回归 |

这些是手工规则核对，不是自动测试或可玩验收。完整随机供给、弱开场、实际消费与三阶段成长尚未联合证明。具体对象摆放应满足至少一条必要解法，不保证任意玩家摆放或战力都可完成。
