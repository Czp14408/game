# 新增 UI 美术组件 v1

2026-10-07。依据已认可的整备、悬浮信息、世界信息及战斗统计样稿制作。采用内置 imagegen；源图保留在 `source/`，生成描述在 `prompts.json`。根目录 PNG 为裁切并按最近邻缩小的导出素材，全部为 RGBA PNG。没有覆盖原组件或接入业务页面。

## Godot 导入和布局

- 纹理过滤显式设为 Nearest，关闭 mipmaps；像素素材避免反复缩放。
- 面板采用 NinePatchRect 或 StyleBoxTexture；`manifest.json` 提供纹理尺寸、源图裁切框、内腔和测量出的九宫格边距，边距顺序为左、上、右、下。
- 清单是素材几何清单，没有规定最终页面位置。接入时将其作为生成器的源素材，按正式布局表生成页面清单，再由访问层查询；不把这里的尺寸复制成业务页面坐标。
- 六张矩形面板均有空白底板，文字、按钮、图标、数字、分隔线、冷却及生命填充不烘焙在图片中。
- 背包和战斗栏按最终内腔净宽除以十计算格宽。底板连续，物品方正矩形随占格伸展；技能圆框单独覆盖，不通过面板装饰表示容量。
- 浅蓝系统面板保留原生透明通道。中心 alpha 实测：背包129、状态106、信息116、说明175、菜单165；统计254；小地图中心0。若希望更通透，系统底板节点可先以 `self_modulate.a = 0.55` 试装，文字和图标放在独立节点，保持不透明。最终值需叠到真实场景校准。
- 小地图用独立视口或遮罩裁剪地图内容；外框仅作装饰，不能代替裁剪。

## 动态反馈对应方式

| 已确认功能 | 素材／绘制方式 |
| --- | --- |
| 商店刷新、锁定、技能滚动箭头 | 复用既有按钮组件；不在底板烘焙按钮 |
| 商店售卖区 | 状态或菜单底板可复用；虚线边界与“拖到此处出售”由 Godot 绘制 |
| 合法／非法拖拽落点 | 动态浅蓝／红色矩形覆盖层，宽度按实际占格计算 |
| 原位淡影、其他物品让位 | 实际物品纹理的透明预览实例，不新增固定位置图片 |
| 自动合成与连续升级 | 产物位置的短暂高亮与动态品质文字，整次反馈合并 |
| 操作失败短提示、交互键提示 | 复用说明或菜单底板，内容按当前上下文变化 |
| 当前交互对象轮廓 | 场景对象轮廓效果，由引擎按对象形状绘制 |
| 方形物品／圆形技能边框 | 复用已有物品与技能组件；品质和选择状态独立叠加 |
| 生命条、头像与战斗物品栏 | 复用 `components_v1/` 与 `battle_v1/` 现有组件 |

## 重建与验收

在仓库根运行 `python godot_prototype/tools/build_system_components_ui.py` 可重建导出 PNG 和清单。工序仅裁切源图透明留白、排除框外零散杂点所在的边缘留白，并最近邻缩放；不绘制或替代 AI 美术内容。原图保持完整。

已核对透明通道、导出尺寸、非空内腔，并目视检查导出说明框、背包底板和菜单。尚未在实际 Godot 页面接入，未进行多分辨率运行验收；九宫格在真实页面上仍需检查角部与文字边距。
