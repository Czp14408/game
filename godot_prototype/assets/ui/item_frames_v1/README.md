# 物品像素品质框 v1

每个品质共享一套框体：`bronze` 青铜、`silver` 白银、`gold` 黄金、`diamond` 钻石。普通与选中各一张，选中只增加同品质内框。图片为代码绘制的像素 SVG，32×32 原始尺寸；九宫格边角固定 8 像素，边线延展。全程使用最近邻采样。

卡面外部比例小 1:2、中 2:2、大 3:2，与物品占格对应。悬停框沿用同一品质框资源。物品图案单独提供，不包含在品质框素材中。

统一配置：`theme.json`。展示入口：`content/preview_item_frames.cmd`。替换边框时保留原路径与九宫格切分约定，或同时更新配置。当前是供验收的第一版像素风模板。
