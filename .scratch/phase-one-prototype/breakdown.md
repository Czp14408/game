# 第一阶段原型任务拆分

状态：用户已确认；规格与8项任务已发布GitHub，实际链接见publication.md。所有任务已标记ready-for-agent，有阻塞的任务需等阻塞解除后开工。

主测试边界：试炼控制入口的玩家命令、可见状态、结果和账本。补充边界：独立战斗输入输出；画面交互实际试玩。

| 编号 | 标题 | 阻塞 | 独立交付 |
| --- | --- | --- | --- |
| 01 | 开局并完成首场武器战斗 | 无 | 选择职业血统、入口移动、查看普通土匪、自动战斗、生命与战败结果 |
| 02 | 搜刮交易并装备合成战利品 | 01 | 随机奖励、容器、背包、武器店、买卖刷新锁定、恢复品、装备合成完整流程 |
| 03 | 组建完整机制构筑并理解战斗结果 | 02 | 12主动物品、3技能、技能买学合成、战前联动、战后全来源反馈、完整战斗基准 |
| 04 | 付费探索路线并处理守路遭遇 | 02 | 节点费用与重访、路线锁定、资源保留、城镇与野外布局的可玩路线 |
| 05 | 打听并完成武道主线与支线 | 03、04 | 18节点全部内容、隐藏位置与情报、两项支线追认、头子、主线自动奖励、继续探索选择 |
| 06 | 回归整备并完成第一阶段挑战 | 05 | 不可返世界、治疗商店、九种固定对手、重试、第三败与认输、阶段结果 |
| 07 | 验证三条复演和不同构筑取舍 | 06 | 开发测试入口、三路线断言、三构筑样本、携带压力、真实随机试玩记录与结果 |
| 08 | 导出并验收Windows试玩包 | 07 | 可编辑项目、编辑器外试玩、窗口中文交互检查、日志与已知问题 |

独立分支：03与04在02完成后可分别推进；05等两者完成。没有现有工程，不需要先做重构票。每票均含玩家可演示行为、必要定义与状态、UI、外部行为验证，不按技术层拆分。
